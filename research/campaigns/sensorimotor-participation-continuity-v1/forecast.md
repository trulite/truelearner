# Sensorimotor participation continuity forecast

```text
participation -> local return -> consequence mark -> later selection
      |              |               |                    |
      +-- surface ---+               +-- coalition -------+
                                      `-- recent route
```

The next frontier is not a body-level controller. It is continuity of the same
physical participation across four boundaries: eligibility write/read, first
surface return opening/delivery, per-member coalition lineage, and composition
of the three already surviving boundaries.

| Transition | Status | Strongest evidence | Killing falsifier |
|---|---|---|---|
| Participating route writes state read by the next competition | constrained | LP-032; recent eligibility never continued at ratios 1–8 | The same live link is written and read within the window, yet loses. |
| One action path opens a finite return reached by one local surface | constrained | LP-033; prior cohort fixture had zero updates | A valid path and return deliver an update, but later surface recall still fails. |
| Every jointly consequential member retains common physical lineage | constrained | LP-027, LP-031, LP-032; trained pair recalled one | Both executable members retain equal live lineage and one is still suppressed. |
| Finite return, indexed aging, and origin sparsity coexist | predicted | Three isolated survivors from the parent campaign | Any isolated predicate changes under neutral composition. |
| One joint and later body surfaces recompose | unknown | Actual prerequisites previously failed | A composition fails after every measured prerequisite survives. |

Later fixtures may supply an already measured prerequisite, but may not supply
the association, winner, coalition, or body result being tested.
