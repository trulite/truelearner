# Sensorimotor physical-boundaries ladder

This successor tests the five physical boundaries localized by
`sensorimotor-composition-sweep-v1`. The candidate laws remain anonymous and local:
recent consequence, finite return lifetime, touched topology, causal origin, and
distinct local surface participation. No arm may name an action, body part, target,
score, episode, or correct response inside the learner.

| Arm | Physical transition | Status before run | Killing observation |
|---|---|---|---|
| current-physics-reference | reproduce the five frozen counterexamples | established | any predecessor observation changes |
| recent-eligibility-over-strength | recent local consequence temporarily mediates historical strength | predicted | fresh route loses at ratio 8, durable strength is erased, or no-consequence locks |
| bounded-return-eligibility | a physical return remains valid at delay 20 and expires before delay 200 | predicted | valid delay loses or stale delay credits |
| active-frontier-scaling | execution visits aging or touched structure rather than dormant stable topology | predicted | work or scans grow materially from 4 to 1024 dormant outputs |
| wave-alternative-sparsity | outputs sharing one causal origin compete while independent origins do not | predicted | shared origin emits all eight or independent origins interfere |
| learned-coalition-preservation | outputs with a shared consequential participation cohort survive together | predicted | a trained pair is suppressed or an untrained shared fanout broadens |
| surface-return-cohort | distinct local surfaces may answer one action return once each in either order | predicted | first arrival monopolizes, duplicate/unrelated credit appears, or stale return remains |
| one-joint-recomposition | recent consequence, finite return, selection, and motion close one reflected joint | constrained | either limit is not reached and left |
| binocular-hand-recomposition | paired sensing and a bounded hand coalition compose | unknown | isolated prerequisites survive but paired correction or hand grouping fails |
| vocal-auditory-recomposition | output, delayed acoustic surfaces, and recalled output compose | unknown | isolated prerequisites survive but loop fails or locks |
| full-body-recomposition | one active learned subset operates inside a large dormant body | unknown | prerequisite fails, dormant interference appears, cost grows, or replay differs |

All isolated arms run even when an earlier arm fails. The four recompositions consume
actual arm outcomes and become inconclusive after a required failure.
