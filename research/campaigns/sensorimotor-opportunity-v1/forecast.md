# Sensorimotor control dependency forecast

```text
participate -> open return -> local outcome -> strengthen -> reuse
                                 |
                        no outcome arrives
                                 |
                  one local alternative fires
                                 |
              superseded return closes locally
                                 |
                  consequence selects the route
```

| Dependency | Physical transition | Prerequisites | Evidence and status | Killing falsifier |
|---|---|---|---|---|
| Actual participation | A fired path opens its own temporary way back. | None | CORE1 authority; `established` | Credit appears without participation. |
| Causal-local return | An outcome enters only the way opened by the output that caused the change. | Participation | `sensorimotor-locality-v1` exact isolation; `constrained` because control emergence failed | Correct and shuffled wiring credit the same path. |
| Return lifetime | The way back remains live until outcome or physical supersession. | Participation | CORE1 and LP-002/003/007; `established` within accepted bounds | A valid delayed outcome loses its path without an intervening event. |
| Local alternative exposure | A route still awaiting outcome yields one opportunity to a ready neighbor. | Live return, local competition | `pending-return-deferral` exposed the neighbor; `constrained` by stale shared credit | No fresh neighbor fires, or a far output changes eligibility. |
| Superseded closure | When the neighbor participates, only the displaced unanswered return closes. | Alternative exposure | `pending-return-replacement` closed stale credit; `constrained` by broad coactivation in the old global-return body | The displaced return remains creditable, or an unrelated return closes. |
| Local composition | Exact local return, alternative exposure, and superseded closure preserve credit while producing reversal. | All above | `predicted` | The one-joint body cannot move both ways and leave either reflected limit. |
| Interference isolation | One local opportunity leaves other axes unchanged. | Local composition | Prior broad-coactivation counterexample; `predicted` | A far axis fires, loses a return, or receives credit. |
| Multi-axis reuse | Independent controls compose without shared credit. | Interference isolation | `predicted` | Repeated axes require global coactivation or semantic identity. |
| Binocular, digit, and vocal-auditory control | The same laws transfer across different physical surfaces. | Multi-axis reuse | `predicted` | A surface needs a specialist learner or named body part. |
| Sensory selection and longer sequencing | Active local structure bounds sensing and action over larger fields and time. | Transfer | `unknown`; intentionally deferred | Not testable until the local control stack survives. |

## Inherited counterexamples

- Global return credited both simultaneously participating paths.
- Deferral exposed an alternative but left the stale failed route creditable.
- Replacement closed stale credit but produced broad multi-axis coactivation.
- Exact causal-local return isolated credit yet repeated the strengthened direction at a limit.

## Immediate frontier

Hold causal-local return fixed and compare unanswered-return deferral with local
replacement. Stop at the first one-joint failure. Repeated axes, digits,
binocular control, voice/hearing, multimodal composition, and foveation remain
deferred stages.
