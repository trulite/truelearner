## Complete candidate

The strongest justified candidate retains every established temporal, causal-lineage,
boundary-novelty, private-memory, locality, replay, and quiescence mechanism. Its only
predicted addition is a local factorization of simultaneous completing-path inputs by
their already existing learner owner before candidate executability is evaluated.
Each factor may read only that owner's live-generation consequence memory. Factors
still compete through the ordinary physical candidate rule, so factorization does not
authorize multiple effects.

## Upward ladder

1. In an unrelated mixed-owner fixture, two owner groups reach one output while an
   unrelated third group, a subthreshold group, reversed input order, and an exact-owned
   case remain controls.
2. The complete factorized candidate must produce exactly one lawful effect, read only
   the selected owner's memory, replay exactly, and quiesce naturally.
3. The unchanged reflected hand must improve beyond three changed steps; otherwise the
   mechanism is insufficient even if the fixture passes.
4. Boundary repetition, siblings, adjacent expansion, locality, temporal closure, and
   old core regressions must survive.
5. A held-out mixed-owner world must transfer without benchmark identities or excess cost.

The first failed rung stops dependent rungs. If all rungs pass, freeze the complete
candidate before any necessity claim.

## Competing arms

- Owner-local factorization predicts an executable private candidate and motor output
  while unrelated ownership remains isolated.
- Causal-origin-first factorization predicts the same only when carried physical origin
  separates the owners; it dies if ambiguity remains inside one origin.
- Deepest-common-boundary attribution predicts action only when a consequential common
  ancestor exists; it dies on missing common memory or sibling leakage.
