# Workstation key-selection forecast

```text
ordinary key press -> visible monitor glyph -> returned outcome -> reused path
                                                                  |
monitor shows glyph -> look to keyboard -> find key -> close reach -> press/release
```

## Claim boundary

The external claim is deliberately concrete: after development on ordinary
physical key consequences, a monitor glyph can lead the organism to press and
release the corresponding proper key on the full ANSI keyboard using only
binocular pixels, proprioception, touch, ordinary output, and ordinary device
consequence. Academy owns cue identity and scoring. The organism receives no
text value, key identity, target coordinate, desired action, correctness bit,
reward, or evaluator state.

This is a capability ladder, not an assertion that the current candidate is
sufficient. Each later rung stops after the first actual prerequisite failure.

## Complete candidate

Carry every compatible established or surviving mechanism from the start:

- the accepted connected-outcome product and shared workstation opportunity;
- the real five-digit hand, proper 104-key geometry, collision, pressure,
  hysteretic key-down/key-up, monitor rendering, and visible binocular hand;
- physical-transition-only outcome availability through its first executable
  local choice;
- wide retinotopic sensing, threshold factorization, output-specific visual
  return, one-cause retinal fanout, binocular alignment, and stable fixation;
- learner-only and complete-body fingerprints, lossless choice/return trace,
  exact checkpoint replay, natural quiescence, and bounded work;
- neutral embodiment composition for available sensor values, finished commands,
  actual effects, and post-effect sensing.

Do not add a planner, symbolic key memory, target holder, scan route, semantic
glyph identity, coordinate transform supplied by Academy, correctness channel,
or evaluator-selected finger.

## Upward ladder

1. **World presentation.** A replayable external monitor cue changes only the
   rendered binocular pixels. The full keyboard, its labels, and the visible
   hand remain present. Blank and alternate cues provide identity controls.
2. **Self-caused visible outcome.** Ordinary exploration presses a proper key;
   the device changes monitor pixels; the changed pixels reach the retina and
   learner with the original action's causal return still interpretable.
3. **Key-specific association.** Two different printable key presses leave
   different retained action-outcome paths. Initial development uses proper
   keys whose printed and displayed glyphs do not require case conversion.
4. **Cue-first reverse reuse.** From one identical learner/body/world checkpoint,
   present each learned glyph before a press. The two glyphs must produce
   different path reuse, executable choice, and outward action histories. A
   forward `press -> glyph` relation is never treated as an automatic inverse.
5. **Cue continuity across gaze change.** The cue-specific physical influence
   remains available while gaze leaves the monitor and samples the keyboard;
   blank, unrelated, expired, and resampled-state controls remain negative.
6. **Active keyboard search.** Successive two-dimensional eye movements expose
   keyboard regions and stop at a corresponding printed glyph without a supplied
   route. Fixation is measured from actual photons and gaze effects.
7. **Cross-surface correspondence.** Monitor and keycap forms still select the
   same learned relation under retinal translation. Later probes change font,
   case, scale, lighting, and key position one factor at a time.
8. **Closed visual reach.** Seen-key and seen-fingertip changes compose with
   palm/finger proprioception until one fingertip enters the key surface in x,
   y, and depth. Centered gaze alone is an explicit negative control.
9. **Single-finger press cycle.** One fingertip touches, depresses, produces one
   key-down, observes the ordinary monitor consequence, releases, produces one
   key-up, and returns to natural quiet without neighboring presses.
10. **Scale and transfer.** Interleave two keys, five keys, one row, and a larger
    keyboard subset; then move and rotate the keyboard, swap keycaps, vary font
    and lighting, add clutter and partial occlusion, test retention after unrelated
    work, and require exact fresh-process replay.
11. **Capstone.** Freeze the candidate, checkpoint rule, full keyboard world,
    unseen cue sequence over learned structure, budgets, evidence schema, and
    scoring before one unchanged held-out run. Score only outside the organism.

## First-failure descent

Inspect one retained trace in this order:

1. monitor raster difference;
2. retinal difference;
3. learner-only fingerprint and path formation;
4. exact participating output-to-monitor return;
5. outcome write and later cue-driven read;
6. executable eye choice and actual gaze change;
7. cue influence after monitor leaves the fovea;
8. keyboard fixation and printed-glyph correspondence;
9. palm/fingertip choice and physical displacement;
10. key contact, pressure, key-down, monitor consequence, key-up, and quiet.

Stop at the first missing arrow. Use a neutral fixture only when it supplies a
prerequisite without encoding the transition under test.

## Controls

- blank monitor cue;
- unlearned glyph;
- cue present with keyboard visually unavailable;
- keyboard visible with no cue;
- identical cue resampled without a physical change;
- paired cues from the exact same checkpoint;
- moved keyboard and moved key;
- swapped keycaps to separate appearance from memorized position;
- changed font and case only after exact-glyph reuse survives;
- centered gaze without a closed hand relation;
- neighboring-finger and stuck-key controls;
- exact replay, Production/reference identity, learner-only fingerprinting,
  natural quiescence, semantic-firewall audit, and bounded work.

## Conditional downward ablation

Only after the complete ladder passes, freeze it and separately remove visual
outcome return, physical-transition eligibility, first-choice lifetime,
retinotopy, threshold factorization, cue continuity, foveal identity, retinal
fanout, proprioception, visible hand return, contact, output factorization, and
opportunity factorization. Restore the reference between removals and rerun the
entire ladder. A removal supports necessity only when capability and every
control remain interpretable.

## Active frontier

The first experiment is the composition between the already observed real-key
device consequence and cue-first reuse:

```text
press K -> monitor glyph K -> learner outcome
                              |
fresh monitor glyph K --------+-> later executable action differs
```

Use two proper printable keys inside the unchanged full keyboard scene. Retain
the entire causal slice through raster, retina, learner, candidates, choices,
movement, contact, device events, replay, and quiet so a negative result already
identifies the first broken arrow.
