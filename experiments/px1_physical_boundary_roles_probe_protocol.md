```text

→ PX0 correspondence arrows physically form and mature
```

## Exact PROBE worlds

All worlds use fresh physical identities. Each contains two anonymous source
regions with identical local layouts.

1. **Main world.** Both sources independently acquire retained PX0
   correspondence arrows. Both correspondence endpoints receive identical
   broad opportunity-forming activity. Repeated later source activity traverses
   the learned PX0 arrows; only one endpoint receives lawful downstream return.
2. **Reversed world.** Fresh identities and mirrored allocation; the opposite
   endpoint receives the same physical return topology.
3. **Return-absent control.** PX0 correspondence and endpoint opportunities are
   present, but neither endpoint receives downstream return.
4. **Equal-return control.** Both endpoints receive equally recurrent physical
   return; neither side may be privileged by index or allocation.
5. **Broken-PX0-path control.** Endpoint opportunity and return physics remain,
   but sources are outside PX0's local proposal radius. Source activity cannot
   reach endpoint role structure.
