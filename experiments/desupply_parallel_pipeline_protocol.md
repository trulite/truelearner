## Global invariants

### 1. Prefix-valid cumulative de-supply

The cumulative claim is the longest consecutive positive prefix:

```text
minimal physics -> DS0 -> DS1 -> DS2 -> DS3 -> ...
```

If DS2 cumulative fails after DS0+DS1, a later isolated or cumulative DS3
positive cannot repair or subsidize it. The authoritative prefix stops at
DS1.

### 2. Two explicit result labels

Every result must be labeled exactly one of:

```text
ISOLATED POSITIVE / ISOLATED NEGATIVE
```

The tested scaffold was removed while later and unrelated scaffolds remained
supplied. This may establish reconstruction, function, controls, attribution,
and mechanism readiness. It never advances the minimal-physics mainline.

```text
CUMULATIVE POSITIVE / CUMULATIVE NEGATIVE
```

The scaffold was tested after every earlier scaffold in the frozen order had
already been removed. Only this result advances or stops the shrinking-channel
lineage.

No report may abbreviate an isolated positive to simply `positive`.

### 3. No downstream pressure on upstream interfaces

An isolated downstream mechanism may depend on information that an earlier
cumulative gate later removes. The earlier gate must not be modified to
preserve that dependency.

Allowed:

```text
isolated mechanism
    -> port unchanged physics onto new cumulative parent
    -> compatible: continue
    -> incompatible: freeze dependency/compositional negative
```

Forbidden:

```text
retrofit upstream de-supply
    -> retain a renamed channel because downstream code expects it
```

### 4. Representation/policy de-supply, not physics

All lanes retain the frozen minimal physics boundary:

```text
persistent CELL / ARROW identity
fresh SPIKE occurrence
local temporal precedence
local directional propagation
local mutable / plastic state
ordinary environmental input / output / consequence
```

No lane may remove or reinterpret these merely to make its scaffold test
easier.

### 5. No semantic channel under another name

Leak audits must reject any organism-visible value equivalent to the removed
scaffold, including stable IDs, enum variants, correlation tokens, map keys,
canonical representations, evaluator labels, supplied target boundaries,
expected direction, expected grouping, answers, pass/fail, or economics.

## Three levels of allowed parallelism

### Across isolated scaffolds

Independent scaffold branches and worktrees may run concurrently. Each owns a
distinct persistent E2B state/sandbox and never mutates another lane.

### Across development work for later waves

Wave-II and Wave-III mechanisms may eventually be explored against a frozen
available ancestor. Their scientific status remains `ISOLATED` and their
cumulative claim remains blocked on the complete preceding wave.

### Across cells within one gate

Seeds, scale cells, controls, attribution cells, and leak probes may execute in
parallel. Each organism cell remains single-threaded and deterministic. Frozen
logical work counters, not wall time, remain authoritative.

## Definitive locks
