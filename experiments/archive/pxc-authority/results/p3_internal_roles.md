# P3: Discovered internal execution roles

## Question

Can recurring activity produce reusable working and control-event roles, and
can local structural plasticity construct the recurrent traversal program over
those learned roles?

## P3a: Working roles

Anonymous temporary cells carry opaque identities around an operation.
Irrelevant cells also fire before and after it, serialization changes, and
absolute timing is not used.

```text
successful seeds                       8 / 8
transferred anonymous encodings      256 / 256
retained working roles                     2
permanent receptor identifiers             0
symmetric roles distinguished          false
```

The two retained structures are interpreted after the experiment as the
identity being operated on and the produced identity. When the experience
contains no structural information distinguishing those functions, no stable
distinction forms.

## P3b: Feedback over learned roles

The frozen working-role structures are the only working interface available
to the feedback learner.

```text
feedback discovery seeds               8 / 8
real traversal depths                  56 / 56
retained feedback arrows                    1
```

The same learned feedback arrow carries newly produced identities into the
operated-on role through held-out depths up to 32.

## P3c: Control-event roles

Anonymous event receptors change identifiers and serialization. Recurring
event structure produces two retained roles interpreted after training as
operation initiation and no continuation.

```text
successful seeds                       8 / 8
transferred anonymous encodings      256 / 256
retained event roles                       2
real traversal depths                  48 / 48
continuation / finish arrows             1 / 1
symmetric roles distinguished          false
```

## P3d: Fresh end-to-end discovery

Each seed starts without encounter representations, plasticity values,
sensory roles, working roles, control-event roles or program arrows. It
receives the complete traversal task from its first episode.

```text
competent fresh learners                8 / 8
held-out depth 5-32                   512 / 512
transferred internal encodings        512 / 512
retained sensory roles                       3
retained working roles                       2
retained control-event roles                 2
retained program arrows                      4
average competence episode                48.25
```

The observed emergence order was not supplied as a curriculum. In this task,
all three role populations became usable around episode 4, while the four
program arrows consolidated around episode 48.

Controls:

```text
shuffled terminal feedback              0 / 8 competent
random terminal feedback                0 / 8 competent
```

Held-out evaluation freezes every learned role, encounter representation,
plasticity value and program arrow. Fingerprints remain unchanged.

## Supported claim

> Repeated activity produced reusable sensory, working and control-event
> roles, and local structural plasticity constructed a recurrent program over
> those learned roles.

## Remaining supplied structure

- Broad sensory, working, event and output populations
- Generic local structural signatures and exact matching
- The generic effects of identity-bearing and control events
- Query, start and explicit output boundaries
- Local geometry, growth slots and exploration
- Eligibility, terminal correctness, strengthening and pruning
- Opaque identity equality and temporary lifetime

P3 learns roles inside the supplied broad populations. It does not yet
discover those populations, the event physics or the learning law itself.
