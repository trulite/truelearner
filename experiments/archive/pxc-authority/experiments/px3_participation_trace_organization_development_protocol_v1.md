## Hypothesis

> Reusable event organization can grow when distinct, physically traversed
> paths produce overlapping authoritative PX1 participation-trace firings at
> ordinary local convergence opportunities; returned activity and pressure
> select persistent joint organization, and a selected organization can enter
> the same physical API as one participant in a higher organization.

An event is not an organism-visible object. The transient event is the overlap
of physical trace firings. Reusable organization is ordinary retained
CELL/ARROW structure that survived actual traversal, return and pressure.

## Exact delta from the frozen PX3 negative

The no-addition negative had four independent route motifs and one shared hub.
It contained no physical convergence site at which two distinct PX1 trace
firings could jointly act, so it could retain only route marginals.

This lane adds no substrate law or stored field. Its only PX3 physical
opportunity is a symmetric anonymous convergence reservoir:

- for every unordered local incidence of two available participant outputs,
  one ordinary threshold-two opportunity CELL exists before training;
- each opportunity receives one fixed coupling-one ARROW from each of its two
  physical inputs;
- all opportunity CELLs are constructed identically and all candidate
  incidences exist before the reference schedule; no evaluator selects or
  creates the trained incidence;
- one participant supplies at most one unit because the inputs are
  authoritative PX1 trace-CELL firings, not raw source coupling;
- an opportunity CELL has no semantic field, pair label, member list, event
  identity, provenance, or evaluator-visible selection bit.

The reservoir is new PX3 topology, not a new kind of object or law. It is the
ordinary local-opportunity surface explicitly absent from the earlier
no-addition arm.

## Existing-physics organization path

Every opportunity CELL has one nearby ordinary consequence CELL. Candidate
opportunity->consequence ARROWs must be created uniformly through PX0's
existing generic local proposal path, never only for a scheduled or expected
pair:

1. the evaluator supplies the same external opportunity pulse to every
   anonymous opportunity CELL;
2. ordinary threshold firing generically proposes the only nearby ARROW at
   physical distance two, giving delay/resistance `2` and coupling `1`;
3. the proposal's initial unsupported emission receives no context/return;
4. ordinary expiry reduces the candidate to resistance `1` while leaving it
   live for a real co-participation opportunity;
5. overlapping trace inputs fire only their physical convergence CELL;
6. its candidate traverses and coincides at the consequence with one identical
   shared context unit;
7. consequence activity reaches a shared return hub, which broadcasts the same
   ordinary return to every opportunity CELL;
8. only the opportunity whose candidate actually traversed has live local
   eligibility and strengthens;
9. recurring return raises resistance enough to survive the fixed pressure
   gap; unsupported candidates deallocate;
10. after environmental change, ordinary pressure removes unsupported old
    organization, and the same uniform proposal exposure can repropose the
    complete anonymous reservoir.

All context, proposal and return pulses are uniform physical opportunities.
They carry no incidence identity and never inspect expected results.

## Authoritative participation input

Every primitive participant uses the authoritative PX1 normalization topology:

```text
raw source/path coupling
```

must not multiply trace firing. Same-path repetition must be serialized as

4. participation-trace arrival/firing and expiry;

Nearby activity that did not traverse an incident input path is
nonparticipation. Scheduled pulses, semantic names and expected results never
