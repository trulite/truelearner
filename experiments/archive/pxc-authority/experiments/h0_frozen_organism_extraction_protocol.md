# H0 Frozen Organism v1 extraction PROBE protocol

Status: preregistered development PROBE. This protocol authorizes no
definitive evidence and no organism modification.

## Question

> Can the cumulative M0--M8 mechanism be mechanically extracted, without a
> new representation or semantic routing layer, into a genuinely blank,
> reusable, continuous Frozen Organism v1 runtime?

## Required runtime surface

A positive path must already support an interface equivalent in physical
content to:

```text
blank(fresh namespace, capacity)
arrive(anonymous physical events)
advance(work bound)
take outward physical crossings
snapshot / restore
complete fingerprint
permanent fingerprint

evaluator-only:
inspect permanent structure and temporary activity
```

Names and Rust signatures may differ. The physical capabilities may not.

## Blankness requirements

A blank instance must contain the frozen learning mechanisms but zero learned
childhood/world content. Construction must not:

- generate acquisition episodes or streams;
- install fixed roles/programs or world relations;
- derive content from a seed;
- construct productive/distractor encounter classes;
- provide a target, answer, query, terminal, request, or closure fixture.

Fresh namespace and capacity are physical configuration, not learned content.

## Continuity requirements

The external runtime surface must contain no semantic lifecycle operation such
as `begin_episode`, `end_episode`, `reset_task`, `erase_episode`, or equivalent.
Temporary activity must disappear only through the frozen organism's ordinary
dynamics. The evaluator may observe quiescence but may not cause it.

## Mechanical audit

Starting at authoritative post-M7 DS5/M8 execution, trace backward from its
physical output crossing to its input and update paths. For each required H0
surface, classify the exact implementation as one of:

- `EXTRACTABLE`: existing state and transition can be moved byte-preservingly;
- `FIXTURE-BOUND`: transition consumes experiment-generated structured data;
- `SEMANTIC-BOUNDARY`: transition requires a supplied task/episode meaning;
- `ABSENT`: no path exists;
- `NEW-REPRESENTATION`: a general raw-arrival path would have to be invented.

The audit must record at least:

1. blank construction;
2. anonymous external arrival;
3. continuous advancement;
4. outward crossing;
5. learning/update path;
6. ordinary transient decay/quiescence;
7. snapshot/restore;
8. complete/permanent fingerprints;
9. evaluator-only observation.

## Pass condition

All nine surfaces are `EXTRACTABLE`, frozen source hashes remain exact, and a
mechanical move can begin without selecting among new representations or
introducing semantic lifecycle information.

## Negative condition

Freeze the first required surface that is `FIXTURE-BOUND`,
`SEMANTIC-BOUNDARY`, `ABSENT`, or `NEW-REPRESENTATION`. Do not implement a
wrapper that converts anonymous physical events into experiment fixtures.

The negative claim must be narrow:

> The authoritative cumulative mechanism is not mechanically extractable as
> H0 under the frozen no-new-representation rule.

It does not invalidate M0--M8 within their authoritative matrices. It says the
matrices did not yet establish a self-contained continuous organism runtime.

## Stopping rule

On a negative, stop H0 implementation and return the exact missing edge. Any
proposal to create that edge belongs to a separately authorized integration or
architecture-research program, not cleanup.
