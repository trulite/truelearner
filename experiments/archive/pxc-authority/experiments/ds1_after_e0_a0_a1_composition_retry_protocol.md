## Exact composition boundary

One frozen E0 acquisition instance produces the support episodes, one actual
target event, its temporary learned relations, and the existing DS1
`Neighborhood`. A format-only composition shim copies the same target event
fields into the frozen A1 input schema one-to-one. It may not infer members,
relations, ranks, actions, consequences, or meanings.

The frozen A1 learner then:

1. observes ordinary current-member propagation relations;
2. consolidates anonymous role-relative templates;
3. installs episode-local CELL/ARROW roots;
4. structurally deduplicates them;
5. bridges every remaining root one-to-one to an opaque handle; and
6. exposes the handle count only after the roots already exist.

The bridge gives frozen DS1 only an arity and an opaque index-to-handle
reference. It does not construct, interpret, rank, score, or name an action.
Frozen DS1 receives the exact existing `Neighborhood` and calls its unchanged
`choose` method. The selected opaque handle may then inject a root SPIKE and
execute only through the already-installed live adjacency.

Any post-choice evidence at stage 7 must already exist as a natural path from
that physical execution into the frozen DS1 interface. The composition harness
may inventory or report such a path; it may not add an observer, translate an
effect into a boolean, manufacture a consequence, call
`apply_consequence`, or supply correctness. If no such path exists, stage 7
collapses and stages 8–9 remain blocked.

## Ordered stages and stopping rule

The exact stages are:

0. M0 lineage, learned/compiled correspondence fingerprints, and frozen
   correspondence controls remain valid;
1. frozen E0 forms the actual learned local event;
2. exact one-to-one E0-to-A1 transfer succeeds with no serializer inference;
3. the same actual target event has at least two independently formed,
   structurally unique, executable A1 roots before bridge;
4. at least two opaque one-to-one alternatives are visible to frozen DS1;
5. byte-identical frozen DS1 actually chooses one available opaque
   alternative;
6. the selected root physically executes through ordinary live
   CELL/ARROW/SPIKE propagation;
7. frozen DS1 receives whatever post-choice evidence already exists through
   the current substrate;
8. frozen DS1 updates through its unchanged existing update path;
9. boundary-role reconstruction and the frozen isolated functional controls
   succeed.

The first false stage is the only collapse. Every later stage is `BLOCKED`,
with blank work/storage fields where the corresponding operation never ran.
No rescue follows in this lane.

Only passage through stage 9 can create an M1-eligible development outcome.
Even then, M1 is not created until a separately authorized cumulative freeze.
