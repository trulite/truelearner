## Interleaved context world

One continuous blank substrate contains two focal correspondence candidates,
a stable return gate, multiple physically distinct support devices, and local
distractor sources capable of creating genuine incidental return paths.

Every context activates both focal candidate sources. Four context forms are
interleaved in repeated cycles:

1. stable return and incidental return both physically occur;
2. stable return occurs through a different device identity; incidental return
   is absent;
3. stable return occurs with a different device delay/arrival schedule and
   changed distractor activity;
4. stable return occurs while a different local accidental opportunity appears
   elsewhere.

The stable route receives ordinary return in every context, but through four
support devices with distinct physical identities, positions, and delays. The
incidental route receives ordinary return only in context form 1, when a
nonmatching source physically lies within proposal radius of its gate and is
active. Its return is not blocked or discounted when it occurs.

Contexts are presented in literal interleaved order, not stable training
followed by incidental testing. Physical pressure acts continuously between
contexts. There is no reset.

## PROBE

Use two fresh mirrored arms:

- arm A: route 1 stable, route 0 incidental;
- arm B: route 0 stable, route 1 incidental.

Run eight four-context cycles plus a final three-context tail without the
focal incidental driver. Context bases are separated by 12 ticks. Candidate
activity occurs at base+2; one of four stable support devices is activated at
the physically appropriate earlier tick so its delay reaches the stable gate
at base+4. Incidental driver activity, when present, reaches its gate at the
same physical time.

The unchanged local proposal radius, coupling, eligibility, return strength,
ordinary pressure, and deallocation law apply.

After interleaving, require:

1. both stable and incidental proposals formed;
2. both routes received genuine physical return at least once;
3. the stable route received return across all four device identities/delays;
4. stable resistance accumulated and its structure remained live;
5. held-out stable activity produced exactly one outward crossing;
6. the final incidental generation received no return, remained subthreshold,
   produced zero outward crossing, and disappeared under pressure;
7. old incidental generations stayed stale;
8. all activity became naturally quiescent;
9. work, storage, proposals, returns, deallocations, identities, and
   fingerprints were accounted;
10. complete-state duplicate replay was exact.

## Hard anti-cheat rules

Forbidden:

- a stable/incidental, correct/wrong, context, relation, or route label in
  active state;
- evaluator-selected mutation, deletion, retention, or execution;
- discounting return based on which device or distractor caused it;
- resetting structure between context forms;
- a stored cross-context reliability score or context identifier;
- hard-coding route B, support-device identities, or the four-form schedule.

The evaluator may construct physical worlds, observe traces and structure, and
calculate recurrence externally. It may not feed those observations back.
