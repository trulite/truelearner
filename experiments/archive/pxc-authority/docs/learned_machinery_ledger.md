# M0--M8 learned machinery ledger

Status: **authoritative cumulative ledger**.

This ledger places every cognitive and control function on the learned side
of the substrate boundary. “Originally supplied” identifies the information
removed by the corresponding de-supply step; it is not part of the final
organism contract.

## M0 — correspondence

- **Originally supplied:** filler/occurrence equality and direct identity
  correspondence used by the recursive execution path.
- **Organism-visible replacement evidence:** recurring local coactivation,
  context, support, dependency validation, ambiguity, and reuse across fresh
  occurrences.
- **Learned structure remaining:** compiled correspondence structure that
  relates fresh occurrences without retaining a semantic equality token.
- **Compilation and execution:** learned correspondence is compiled into the
  existing local recurrence/binding path; mature execution reuses that path
  and preserves the parent observable trace.
- **Authority:** `ffs-same1-compiled-correspondence-positive`, commit
  `0c81f80397c8b28e7586cd598d00114de1a8a788`; [result](../results/ffs_same1_compiled_correspondence.md),
  CSV SHA-256 `7883f71918d48c4c622d7cd2d9dd7561f5954f7287f8bc6abb535f5a9f994a55`.

## Ledger conclusion

The retained substrate supplies only the physics in the
[final substrate contract](final_substrate_contract.md). Every cognitive or
control interpretation in the M0--M8 chain is backed by learned structure and
an immutable cumulative authority experiment. The ledger therefore provides
an explicit audit boundary against reintroducing semantic machinery during
cleanup or later capability work.
