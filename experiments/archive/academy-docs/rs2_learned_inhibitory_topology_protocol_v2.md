
unsupported relation locally decays and its orphan junction disappears.


return `W -> A` and learned `C- -> A` arrive at the same tick with existing
phase ordering: negative phase 0, positive phase 1. The selected `-1` relation
therefore cancels the return locally after B's intended first firing. There is
no stability score, cycle detector, semantic inhibitor role, or post-training
