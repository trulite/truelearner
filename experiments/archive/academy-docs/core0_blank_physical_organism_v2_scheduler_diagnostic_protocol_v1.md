# CORE0 v2 scheduler diagnostic protocol v1

The diagnostic changes only stderr markers. Immediately before a gate run it
prints:

```text
profile gate mechanics replay-index
```

The CORE0 v2 runtime, worlds, admissions and predicates remain byte-identical.
The diagnostic stops on the same panic. The last marker classifies the exact
site. It publishes no scientific row and cannot be used as CORE0 evidence.
