# CORE1-E17 — Local Symmetry-Breaking Tournament Protocol v1

## Status

Four-arm mechanical sufficiency tournament rooted at the frozen E16 result
`2d97ed9`. The accepted organism/runtime remains byte-identical. R, D, and T
are isolated candidate physical laws and gain no authority from this gate.

V19 supplies a design constraint, not inherited route physics: transient
problems should be solved by transient state that disappears with the
interaction rather than by permanent task knowledge.

## Question

When several opaque motor routes are equally eligible and one unresolved route
would otherwise repeat, which smallest local temporary law makes every
alternative eventually participate?

Every candidate must be local, temporary, bounded, blind to usefulness,
naturally quiescent, replayable, and superseded by ordinary consequence
learning once an action works.

## Arm V — bounded blind variation reference

Reuse E16-V exactly. Four blind events visit the four eligible opaque routes
once in frozen replayable seed order. V is known-sufficient reference behavior,
not an adopted stochastic law.

## Arm R — route refractory

Actual route participation writes one episode-local binary refractory state at
that continuation contact. A refractory route is unavailable to later
self-triggers in the same unresolved interaction. Unused routes remain
eligible. All refractory state clears when the interaction ends.

R has no timer, action value, usefulness, consequence, durable effect, or
randomness.

## Arm D — transient efficacy depression

Every route has local transient available efficacy initialized from its durable
coupling. Actual participation depresses only that available efficacy by the
substrate's existing material relaxation fraction (`1/16` per participation;
`15/16` remains). Deterministic local competition chooses greatest available
efficacy, resolving ties by the frozen opaque physical opportunity order.

Depression relaxes toward zero with the existing `15/16` material relaxation
law and clears at interaction end. It changes neither durable coupling nor
resistance. Unlike R, a sufficiently stronger durable route may remain
competitive after use.

## Arm T — local usage trace

Actual participation adds one ordinary material participation impulse to that
route's temporary usage trace. Traces relax by the substrate's existing
`15/16` participation law. Among otherwise eligible unresolved routes,
deterministic local competition favors the least currently used route; frozen
opaque physical opportunity order resolves equal traces.

T introduces no new stored field when the existing participation material is
sufficient. It changes only what equal unresolved continuation competition can
physically sense. Trace magnitude is not a visit counter, action value, or
usefulness estimate, and it cannot alter durable material directly.

## Stage 1 — tiny adversarial kill gate

Before constructing Academy bodies, run all four mechanisms through a tiny
mechanical fixture containing four equal opaque eligible routes under eight
balanced permutations.

Require:

- first participation in one trigger;
- all four routes participate within four triggers;
- useful route appears in its preregistered permutation position;
- no route semantics or usefulness lookup;
- no durable state change;
- temporary state returns exactly to baseline at interaction end;
- work is bounded and linear in route count;
- deterministic replay;
- exhaustion naturally quiesces.

Also run route counts `1, 2, 4, 8, 16` as a scaling diagnostic. Any candidate
that fails Stage 1 is killed and cannot enter Stage 2. No repair occurs inside
the tournament.

## Stage 2 — frozen E16 body

Every Stage-1 survivor runs the same two-opportunity E16 matrix. The same
organism state continues across attempts within an unresolved interaction; an
interaction ends when a motor action changes the world or no candidate remains.
Only the physically useful branch receives ordinary consequence. Temporary
candidate state then clears before the second fixed opportunity.

For every arm and seed require:

- first action: `8/8`;
- useful route participates: `8/8` in both opportunities;
- useful action becomes autonomous after two ordinary consequences: `8/8`;
- bounded PhysicalWork;
- natural quiescence;
- exact replay;
- Reference equals Production;
- action IDs, slots, sign placement, and order do not encode usefulness;
- no temporary state appears in durable body material after interaction.

## Ranking

Rank only candidates satisfying every winning requirement:

1. least new physics;
2. most local interaction;
3. least supplied authority;
4. deterministic replay;
5. smallest transient state;
6. best scaling.

The tournament may identify multiple sufficient mechanisms. It does not adopt
one into accepted physics.
