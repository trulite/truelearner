# CE0 consequence-supported efficacy protocol v1

Status: frozen before any CE0 substrate or evaluator edit.

Parent: CR0 development-positive handoff at `d08997f`.

## Question

Can qualified Modulatory consequence meeting continuous, contact-local
participation mature transmission efficacy by one general local law, without
restoring the historical unconditional `coupling += 1` rule or consulting a
target, task, threshold, desired output, route identity, or supplied credit
horizon?

CE0 is a development gate. It does not resume FD2, run ARC, change authority,
change the oracle, or edit `arch.md`.

## Frozen candidate law

The existing local quantities are retained:

- traversal adds a universal `PARTICIPATION_IMPULSE` to the traversed ARROW's
  continuously relaxing `participation_level`;
- qualified Modulation at the same physical compartment contributes the
  remaining `participation_level` to that ARROW's `plastic_support`;
- resistance consolidation remains byte-for-byte the existing graded local
  return law.

CE0 adds exactly one efficacy consequence to that same qualified coincidence:

```text
support_before = plastic_support
support_after  = support_before + remaining_participation

completed_before = support_before / PARTICIPATION_IMPULSE
completed_after  = support_after  / PARTICIPATION_IMPULSE

coupling += completed_after - completed_before
```

Thus a complete universal participation quantum matures one universal physical
impulse of efficacy. A weaker remaining trace contributes proportionally and
must combine with later genuine qualified coincidences before a whole efficacy
impulse exists. A stronger contact-local participation state may cross more
than one quantum in one consequence. The rule never reads the destination
CELL's threshold, activation, firing, region, output, or desired behavior.

`plastic_support` remains transient causal state and is preserved by the live
checkpoint. An incomplete quantum is not part of the durable body version.
Only coupling changes are durable. CE0 introduces no new state field, target,
ceiling, normalization, decay law, or efficacy decrease. Machine-integer
saturation remains only an unreachable representation guard and cannot be used
by any CE0 world or predicate.

The candidate is feature-gated as `ce0` so the accepted parent and all existing
default-feature evidence remain byte-behavior-identical.

## Static prohibitions

The CE0 substrate edit must contain no equivalent of:

- target threshold, target firing, target state, correctness, desired output,
  reward, route/path identity, predecessor, parent, depth, or hop count;
- an unconditional update based only on `participation_level > 0`;
- `coupling += 1` independent of accumulated participation magnitude;
- a benchmark-specific coupling target or ceiling;
- coupling attenuation, normalization, homeostasis, cycle detection, TTL, or
  rescue damping;
- any eligibility or forgetting-law change.

The only permitted new physical observation is a feature-gated `Coupling`
transition recording ARROW identity and before/after efficacy.

## Frozen matrix

Use two fresh identity roots, all ten absolute clock phases, ReferencePhysics
and selected ProductionBody, and exact same-mechanics replay. Each family is
constructed independently from a fresh body.

1. **No consequence.** One real traversal with no Modulation leaves coupling
   unchanged.
2. **Repeated use only.** Many real traversals without qualified Modulation
   leave coupling unchanged.
3. **Prompt qualified consequence.** One full local participation quantum plus
   prompt qualified Modulation changes coupling `1 -> 2`.
4. **Wrong or late consequence.** Wrong-contact Modulation changes neither
   contact; Modulation after the actual contact's participation has fully
   relaxed changes no coupling.
5. **Graded magnitude.** Weak, full, and double remaining participation
   produce distinct support accumulation. The coupling change must equal the
   number of universal support quanta actually crossed, not a Boolean
   participation predicate.
6. **Repeated supported consequence.** Repeated real traversal plus qualified
   consequence can mature additional efficacy; each change must be explained
   by accumulated contact-local support.
7. **Threshold family.** Physical targets with thresholds 1, 2, and 3 establish
   that efficacy is not fitted to a threshold: coupling 1 already acts at
   threshold 1; one supported quantum makes threshold 2 executable; threshold
   3 requires more supported history. A two-input threshold-2 control remains
   executable without any coupling learning.
8. **Equal persistence, different efficacy.** Equal-resistance routes with
   coupling 1 and 2 retain CR0's different physical effect while having equal
   durable lifetime.
9. **Fan-out locality.** A qualified consequence changes only locally
   participating outgoing contacts. If two outputs of one compartment both
   genuinely participate, both may mature; no one-winner claim is permitted.
10. **Recurrent stability.** A reciprocal delay-one, threshold-two topology
    settles before efficacy learning. After each direction receives genuine
    supported coincidence, a fresh probe must still naturally quiesce without
    re-firing the initiating CELL. Any repeated reciprocal excitation is a CE0
    negative even if local forgetting eventually deletes the ARROWs. No
    ceiling, damping, ordering repair, or cycle rule may be added.

The evaluator must serialize every row before aggregate assertions. The
recurrent family is a hard scientific predicate, not merely a work diagnostic.
