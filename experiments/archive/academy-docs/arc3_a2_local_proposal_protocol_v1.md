# ARC3 A2 context-local proposal diagnostic protocol v1

Status: frozen after the A2 birth-time-reservoir negative and before successor
implementation or execution.

## Question

Can the unchanged TrueLearner laws support four sequential novel visual
contexts when each context creates its weak motor opportunities only when that
context physically arrives?

## Frozen distinction

The failed v1 regimen created all 4,096 resistance-1 context/motor candidates
at body birth. Ordinary pressure lawfully removed candidates for contexts that
had not arrived by tick 10.

This diagnostic removes only that birth-time supply. For every context/motor
pair, the body contains durable local cells and scaffolding, but no weak
candidate ARROW:

```text
context source      motor site
      o                  o
      |<-- distance 1 -->|

first external raster arrival makes context source fire
    -> unchanged propose_local_arrows() sees the nearby motor site
    -> ordinary resistance-1 Drive ARROW is proposed
    -> the newly proposed ARROW participates immediately
```

The motor site still requires two units. The proposed route supplies one and
the development-only ordinary babbling pulse supplies one. A real changed
official raster then uses the existing context trace, actual motor trace,
Modulatory transmission, eligibility, resistance, and pressure laws to credit
only the route that traversed.

No proposal is created for an unseen context, so pressure has nothing
speculative to remove there.

## Laws that remain byte-identical

- Drive and Modulatory transmission;
- CELL thresholds, decay, and refractoriness;
- ARROW traversal, coupling, eligibility, and generation;
- ordinary and unsupported-use pressure;
- local variation radius and proposal resistance/coupling;
- crossing, quiescence, and physical ordering;
- the canonical TrueLearner source under `truelearner/`.

The diagnostic must not protect weak candidates from pressure, reset physical
time, replenish resistance, increase the proposal radius, or inject an ARC
action, goal, score, or level label into the body.

## Frozen physical layout

- spatial context sensor: the accepted 1,024-site raw-raster fingerprint;
- one local motor site per context/motor pair, exactly one position unit from
  its context source;
- one fixed motor-site to outward-boundary continuation;
- motor identity decoded outside the organism from the crossing's physical
  motor class;
- all other attribution scaffolding identical in function to A1;
- no prebuilt source-to-motor candidate in spatial mode;
- dominant-palette A1 construction remains byte-for-byte behaviorally
  compatible.

## Development row

Use the same official `ls20` game, seed `205`, fixed curriculum `[1,4,2,3]`,
and action map `[1,2,3,4]` as the spent A2 v1 run.

For each of four distinct raw-raster contexts:

1. the first context arrival must create the corresponding local proposal;
2. babbling plus that proposal must produce exactly one expected motor crossing;
3. the official next raster must differ;
4. the next observation must produce exactly one qualified update for the
   previously traversed proposal;
5. the proposal must reach coupling 2 and remain live;
6. novel contexts arriving after tick 10 must still be able to create their
   first proposals.

## Frozen probe and controls

After the four development turns:

- reset only the official environment;
- replay the four contexts with no babbling and no modulation;
- require exactly `[1,4,2,3]` from the four retained local proposals;
- require zero updates during replay;
- require all transitions to quiesce;
- repeat the complete diagnostic and require byte-identical normalized
  evidence.

Controls:

- an unseen context has no source-to-motor ARROW before its arrival;
- context arrival may propose uniformly but cannot mature without traversal
  and changed-raster return;
- renewed Drive cannot replace Modulatory credit;
- A1 dominant-palette tests remain positive;
- no file under `truelearner/` changes.

## Decision

PASS means existing just-in-time local variation solves the opportunity-
lifetime failure and makes A2 eligible for a fresh ladder successor.

FAIL freezes the first exact physical edge and stops. It must not be repaired
by changing pressure, proposal strength/radius, or retained physics within this
diagnostic.
