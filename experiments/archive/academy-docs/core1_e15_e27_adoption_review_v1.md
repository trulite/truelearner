# CORE1 E15-E27 — Adoption Review v1

## Decision summary

The successful chain can be compressed into four functional laws. Existing
PQLC remains unchanged.

| Final function | Evidence | Adoption judgment |
|---|---|---|
| Complete route genesis | E23 localization + E24 Gate 1 | **retain E24 law** |
| Motor-local participation | E25 G `0/8`, W `0/8`, G+W `8/8` | **retain G+W as one package** |

The exact experimental implementation is not automatically the final API.

all candidates globally.

## Proposed minimal CORE1 physics

### 1. Atomic complete-route genesis

When source activity and a local motor-side opportunity coexist at a contact,
the physical proposal event may form the complete temporary route in that same
causal window:

```text
source -> contact -> target
```

E23 showed unchanged E14 had source, trace, babbler, and isolated arrow
activity but no complete live pair. E24 repaired exactly that transition. E24
alone did not solve the frontier, but its route-formation function is required
by the successful composition.

**Adopt the law, not E24's former claim of standalone sufficiency.**

### 2. Motor-local signed admission plus causal-wave integration

Generated opposite-signed contacts are alternatives until local competition
resolves; they must not cancel algebraically before admission. A motor also
retains incidence only within the currently open physical causal wave and
clears it at quiescence.

E25 isolates both requirements:

```text
G only     no motor action
W only     no motor action
G+W        motor action 8/8
```

Neither law is sufficient alone in this body. Their composition is required
for the first useful causal action and should be reviewed, tested, and enabled
as one motor-local package.

### 3. Atomic participation-born temporary credit return

When a route actually participates, that event creates the minimum temporary
physical return path by which later consequence can reach the used contact.
Consequence traverses the edge into unchanged PQLC and removes it.

This is E22's earned primitive. It stores only physical endpoints—no action,
episode, path list, expected result, timeout, or reward payload.

E20 proved passive pending topology cannot admit credit. E21 proved post-hoc
wire construction is too late. E22's atomic genesis passed `8/8` and the full
E14 integration again used it exactly.

**Adopt E22 directly.** It is the strongest independently earned law in the
ladder.

### 4. Consequence-born executable route consolidation

Successful PQLC on a complete used route must leave that physical route both
re-enterable and executable by ordinary later source activity. Consolidation
preserves sign and supplies only the locally required efficacy to reach each
target's existing threshold.

This final law should compress E26 and E27:

```text
successful PQLC
-> consolidate the actual used route as durable re-enterable topology
-> close its signed efficacy to local target thresholds
-> later SourceFires propagation executes it normally
```

E26 established the re-entry requirement but its standalone passive edge was
inert (`0/8`). E27 made the two physical route halves executable and passed
`8/8` against an E26 baseline that remained silent.

**Do not adopt E26 as an independent primitive.** Its useful content is the
topological half of the combined E27 consolidation law.

The current E26 implementation creates a new source-to-contact edge even
though the used route already had an incoming stem. Evidence establishes the
required re-enterable executable topology, not that a duplicate edge is the
minimal final representation. Final implementation review should prefer
consolidating the actual used halves if that preserves the proven behavior.

## Existing law retained unchanged

PQLC remains the credit operation. The ladder does not justify a new learner,
reward rule, policy object, recall operator, or symbolic memory. The legacy
E14 update-count mismatch is positive evidence that PQLC follows the actual
two-half topology; it is not grounds to suppress one valid local update.

## Adoption conditions

Before globally enabling the selected laws, perform an implementation and
regression review—not another mechanism search:

1. expose the four laws as the smallest coherent default surface;
2. collapse E26+E27 into one consolidation concept while preserving the frozen
   E27 and full-E14 observations;
3. keep E24 and G+W locally scoped to generated route/motor compartments;
4. preserve E22 consequence-only cleanup and zero passive pending metadata;
5. verify checkpoint/reconstruction preserves the resulting physical route,
   efficacy, and later ordinary execution without a hidden marker dependency;
6. run historical CORE1 controls, sign/cancellation controls, action-map
   invariance, replay, Production equivalence, quiescence, and bounded-work
   checks with candidates enabled by default;
7. retire or clearly quarantine the rejected experimental enable surfaces so
   they cannot silently compose into accepted behavior;
8. preserve E14's original result and replace its scalar update-count check
   only in a separately versioned successor contract.

## Adoption recommendation

Advance the following package to **candidate CORE1 adoption review**:

```text
atomic route genesis

+ unchanged PQLC
```

Do not advance the exploration/continuation/pending-state ladder as accepted
