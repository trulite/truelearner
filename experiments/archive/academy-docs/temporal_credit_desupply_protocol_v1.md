# Temporal Credit De-supply protocol v1

Status: frozen methodology before candidate implementation or execution.

The ARC A2 rectangular-window result remains frozen development evidence. It
is not authority for the eligibility-aware pressure candidate. ARC A3-A5,
`arch.md`, and the architectural oracle remain unchanged.

## Scientific question

Can temporal-credit behavior arise from general local physical dynamics
without a supplied credit horizon, an eligibility predicate, or a special
pressure exception?

The branch must not optimize the existing value `4`. ARC is an unchanged
adversary after de-supply; it must not select the replacement mechanism.

## Branch ladder

```text
TC-DS0  characterize the old rectangular window
TC-DS1  introduce ordinary continuous participation state
TC-DS2  establish renewal by actual path-local participation
TC-DS3  establish local competition among participation, pressure,
        modulation, and resistance
TC-DS4  delete explicit ARROW eligibility
```

Each stage requires a separately frozen stage protocol before implementation
or evidence. A failure stops the ladder. A later stage may not relabel or
overwrite an earlier negative.

## Invariant guardrail

No mechanism may encode how long the organism is willing to wait for credit.
It may encode only ordinary physical state whose local evolution determines
whether later qualified modulation can still interact with prior physical
participation.

The following are forbidden as de-supply candidates:

- changing `LOCAL_WINDOW` or selecting a better fixed window;
- a deadline, timeout, countdown, age threshold, or equivalent hidden clock;
- `trace = N; trace -= 1; if trace > 0` or an equivalent rectangular horizon;
- a per-world, per-task, per-path-delay, or curriculum-selected time constant;
- `if eligible/trace/live { skip_pressure() }` or an equivalent explicit
  protection branch;
- renewal caused by source activity, nearby activity, correlation, generic
  Drive, or generic Modulation without actual traversal of the same path;
- ARC identity, action, score, terminal state, expected return time, or
  evaluator information entering the organism;
- duplicate reference and production learning laws.

A universal relaxation constant is not automatically forbidden. It must be an
ordinary substrate time constant, independent of the task, and its state must
evolve as local dynamics rather than reproduce a rectangular credit horizon.

Static and behavioral audits must enforce these prohibitions. Passing prose
review alone is insufficient.

## TC-DS0 — old-window characterization

Keep the existing `eligible_until` law and `LOCAL_WINDOW = 4` byte-identical.
Sweep return delay, pressure phase, temporal interference, and path
organization only to expose the rectangular window's geometry.

No value is selected, ranked, or promoted. The result must serialize:

- traversal tick;
- modulation tick and delay;
- pressure epochs;
- whether eligibility was live;
- plastic update count;
- resistance/coupling trajectory;
- deallocation;
- physical trace, quiescence, and replay.

## TC-DS1 — continuous participation state

Actual path traversal may change ordinary path-local physical state. Time and
local dynamics relax that state toward baseline. Qualified modulation may
interact with the state that physically remains.

DS1 fails if its state is observationally or mechanically a renamed deadline
or countdown. The test is not whether it happens to last four ticks.

## TC-DS2 — path-local renewal

Only actual traversal of the same physical path may renew its participation
state. These must not renew it:

- activity near the path;
- activity at its source without traversal;
- traversal of another path;
- unrelated Drive;
- unrelated Modulation.

## TC-DS3 — local competition

Participation state, ordinary pressure, qualified modulation, and resistance
must interact through one local physical substrate. The implementation may
not encode the desired outcomes as eligibility-specific branches.

Required emergent behavior:

```text
never participated
    -> pressure wins

just participated
    -> remains physically viable for an ordinary prompt consequence

timely qualified modulation
    -> durable strengthening

no qualified consequence
    -> participation state dissipates
    -> pressure eventually removes weak structure
```

## TC-DS4 — delete explicit eligibility

The strongest gate requires removal of `Arrow.eligible_until` and all
eligibility predicates from active runtime and checkpoint formats. Qualified
modulation may change structure only through compatible path-local physical
participation state that remains at arrival.

Removal must preserve exact restart, deterministic replay, reference versus
production equivalence, and retained physical-body behavior.

## Permanent minimal worlds

Every candidate stage must cover, where applicable:

1. Never traversed: pressure removes the weak structure.
2. Traversed plus prompt qualified modulation: durable strengthening.
3. Traversed without modulation: eventual disappearance.
4. Traversed plus unrelated activity: no maintenance.
5. Source activity without traversal: no maintenance.
6. Repeated actual traversal of the same path: lawful maintenance.
7. Modulation after participation state is gone: zero credit.
8. Long delay with a physically maintained causal chain: credit may remain.
9. Two nearby participating paths, one qualified consequence: only the
   physically appropriate path changes.
10. Equal total activity with different temporal/path organization: only the
    maintained causal organization preserves credit.

The corpus crosses:

- pressure phases;
- fresh physical identities and layouts;
- isolated and repeated episodes;
- `MechanicalConfig::REFERENCE`;
- `MechanicalConfig::PRODUCTION`.

Reference and production must share the same physical law and match on
physical transitions, crossings, Drive and Modulatory deliveries, plastic
changes, proposals, deallocations, physical clock and pressure phase,
canonical durable body, canonical pending activity, quiescence, and replay.
Execution cost is excluded from physical equivalence.

## ARC firewall and return gate

ARC A3-A5 remain paused throughout TC-DS0-TC-DS4. Official ARC worlds may not
be used to tune constants, choose equations, or select candidates.

Only after an independently frozen de-supplied candidate passes the complete
minimal corpus and retained runtime conformance may the exact already-frozen
ARC A2 world be replayed unchanged. ARC success validates generalization; ARC
failure freezes a new diagnostic. Neither outcome retroactively changes the
minimal-world evidence.

## Success condition

Success is not that ARC works again. Success is:

> Temporal-credit behavior is generated by general local physical dynamics
> with no supplied horizon, explicit eligibility predicate, or
> eligibility-specific pressure exception.

Authority, `arch.md`, and the architectural oracle remain unchanged until a
separate successor-authority workflow is preregistered and passes.
