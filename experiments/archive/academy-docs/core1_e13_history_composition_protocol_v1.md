## Established principle being reused

SSA2-P established that equivalent executable affordances need no chooser or
RNG. A fixed lawful transient history can give one physical continuation
pre-closure support before another; the same complete state remains fully
deterministic, while a different transient history can realize another route.

```text

```

## Sole fixture composition

Before teaching a context, ordinary context activity creates the existing
signed candidate/contact topology. For one exploratory attempt, both contact
alternatives receive one identical ordinary positive input. One material sign
receives it at the early tick and the other at the late tick. The paired
attempt reverses only that early/late assignment.

```text
history 0:  - contact early, + contact late
history 1:  + contact early, - contact late
```

Both histories are attempted in that fixed order for every context. There is
no feedback-dependent history choice. The environment admits consequence only
after an actual outward action, exactly as before.

The early/late inputs are all admitted before propagation. They target
ordinary generated contact CELLs and use ordinary Drive incidence. The
substrate receives no history bit, sign preference, selected handle, action
target, correctness, reward, or evaluator result.

For each context:

1. present the context once without babble to create the existing candidate
   topology;
2. run history 0;
3. run history 1;
4. allow an actual action to cause the next ordinary world change and
   consequence;
5. after all four mappings, clear the episode and probe each fresh context
   without transient history or babble.

## Acceptance

Require:

- both early/late histories are admitted for every context;
- candidate action topology remains ordinary variation;
- at least one history produces the intended outward action;
- consequence follows actual action only;
- coupling/resistance maturation follows ordinary participation and
  Modulation;
- fresh contexts re-execute `[1,4,2,3]` without history or babble;
- natural quiescence;
- Reference replay and Production exact under wave-normalized physics.

## Hard prohibitions

No chooser, RNG, sampler, winner flag, preferred sign, selected candidate ID,
history selection from output, reward, error, new plasticity law, altered
coupling rule, or runtime change. If the composed fixture reaches a later
failure already covered by accepted physics, that is an integration seam. If
it reaches a genuinely uncovered physical failure, stop and freeze that first
frontier.
