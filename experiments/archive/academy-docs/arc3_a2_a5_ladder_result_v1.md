## Classification

The A1 geometry scales in identity but not in opportunity lifetime:

```text
all 1024 x 4 opportunities created at body birth
    -> continuous physical time advances
    -> pressure removes unseen resistance-1 opportunities
    -> a later novel visual context has nothing left to traverse
```

This means a dense, birth-time candidate reservoir is not a valid continuous
spatial learner. It also made each return pulse fan out across thousands of
dormant attribution relays, producing 8-9 million units of work on supported
turns. Both observations point toward the same next diagnostic: context-local,
uniform opportunity proposal when physical activity arrives, followed by the
existing traversal/eligibility/modulation/pressure law. That hypothesis was
not implemented or tested here.

The run does **not** show that four contextual relations, autonomous action
selection, level completion, or transfer are impossible. It shows that the
frozen pre-created reservoir cannot remain available long enough to instantiate
the third relation.
