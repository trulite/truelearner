# CORE1-E15 — history preference versus consequence-only protocol v1

## Status

Paired developmental discriminator rooted at the frozen CORE1-B E13
composition result `32cd8e4`, E13-D boundary result `c92c64e`, and unchanged
E14 negative `cacced5`.

The CORE1-B organism, generic variation, continuous material learning,
transient-history resolver, PQLC topology, causal-wave semantics, and Academy
world are immutable. E15-H is an explicit candidate preference outside the
accepted organism. E15-C uses only accepted organism physics.

## Question

Does the remembered fact that an exploratory action previously produced
distinguishing evidence need causal force, or can eventual ordinary
consequence make the same perturbation reappear without such a preference?

## Shared unresolved world

Use one frozen spatial context with four opaque available actions. For each of
eight balanced seeds:

- permute action order deterministically;
- permute which action produces distinguishing evidence;
- prime the same CORE1-B generic candidate topology;
- execute every exploratory action once, in the same permuted order and from
  an exact clone of the same unresolved physical snapshot, using the
  already-established transient-history resolver;
- only the opaque useful action changes the evidence state;
- after that evidence, admit the ordinary downstream consequence;
- execute the same useful action once more and admit a second ordinary
  consequence;
- never train until success.

The eight-seed design places the useful action in each opaque permutation
position exactly twice. The random-control schedule selects it exactly `2/8`
times at every probe stage. This count was fixed from seed arithmetic before
any E15 organism execution.

The actual exploratory actions, evidence, consequences, timings, experience
count, body, and budgets are identical for H and C.

Exploratory attempts are separate episodes from the shared unresolved
snapshot. This prevents an earlier action's refractory state or variation from
silently changing the starting condition of a later action. Only the branch
that physically produces distinguishing evidence continues into the two
ordinary consequence experiences.

## Arm H — explicit history preference

When the useful action changes the evidence state, record its opaque action
label in an arm-local preference. On a probe, that preference selects the
already-existing transient physical history that expresses the remembered
action.

This is intentionally an explicit epistemic/history primitive under test. It
does not receive task reward, target coupling, route identity, or correctness;
its sole signal is that the action produced distinguishing evidence.

## Arm C — consequence only

Store no action preference. On a probe, present the unresolved context without
babbling or transient-history selection. The only way the useful perturbation
can reappear is ordinary material maturation caused by the eventual real
consequence and its retained PQLC closure.

## Random-action control

From the same post-exploration, pre-consequence body, select one opaque action
with a preregistered deterministic seed schedule and express it through the
same transient-history resolver. This measures chance action-policy success;
it stores no history preference and receives no learning before the probe.

## Frozen probes

Clone the causally relevant body at three points so observation cannot alter
training:

1. after distinguishing evidence, before real consequence;
2. after one real consequence;
3. after two real consequences.

At every point record whether H, C, and the random control express the useful
action. Also record coupling/resistance of the useful generated route,
modulatory deliveries, updates, PhysicalWork, natural quiescence, and exact
Reference replay/Production equality.

## Interpretation

- `C ~= H`: explicit history preference is unnecessary;
- `H` earlier, `C` later: history preference is an accelerator, not
  fundamental physics;
- `H` positive, `C` negative: epistemic preference is a serious new-physics
  candidate;
- neither positive: the failure is earlier than learning exploration value.

## Prohibitions

No runtime-law change, chooser inside C, RNG, reward, correctness signal,
adaptive training, preferred physical sign, selected route handle, ARC
accommodation, or post-observation repair. H's opaque remembered action is the
single deliberate difference and must remain outside the accepted organism.
