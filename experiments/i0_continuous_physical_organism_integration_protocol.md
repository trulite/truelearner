Status: preregistered development protocol. No definitive I0 execution is
authorized.

- retained CELL/ARROW/SPIKE physics;

- H0 extraction PROBE v1 negative.

Until I0 passes, `Frozen Organism v1` names a target specification, not an

```text
retained substrate physics                 authoritative
```

## Research question

> Can the already-proven M0--M8 mechanisms operate continuously when connected
> only through anonymous CELL/ARROW/SPIKE activity, without experiment-built
> episodes, seeded histories, semantic boundaries, or terminal supervision?

## Only allowed additions

### Anonymous physical event bus

The bus may carry only existing physical fields:

- fresh physical occurrence identity;
- source/target physical identity or local adjacency;
- arrival tick and phase;
- impulse/activity magnitude;
- ordinary local coupling/generation/liveness information.

It may route activity only through physical topology. It may not carry an
episode, task, history, request, answer, correctness, role, relation, route,
capability, teacher, or evaluator tag.

### Continuous scheduler

The scheduler may:

- order pending local activity by existing deterministic physical order;
- advance at most a supplied physical-work budget;
- stop when the budget is spent or no activity remains;
- resume from the exact complete physical state;
- expose ordinary outward boundary crossings.

It may not detect or act on task/episode completion, call a semantic cleanup
path, select a cognitive mechanism by event meaning, or erase temporary state.

## Integration rule

Existing mechanism source remains byte-identical. New integration code may
expose or route an existing physical prerequisite only when the mapping is
one-to-one and meaning-free. It may not construct the structured fixture type
that an old experiment expected.

Examples:

```text
allowed:
spike reaches physically adjacent active trace
→ existing consequence mechanism receives ordinary activity

forbidden:
spike pattern decoded as ProductiveHistory
→ call M6 with constructed history
```

An adapter is invalid if deleting its semantic field names is insufficient to
remove its knowledge of which cognitive situation is occurring.

## Blankness

A new integrated instance may contain the frozen learning mechanisms produced
by the architecture program. It must contain no generated acquisition stream,
seed-derived instance state, episode-specific relation, query, target,
terminal, learned world object, or childhood content.

Namespace and capacity are physical parameters. Two blank instances with
different namespaces/layouts must be structurally isomorphic before ordinary
experience.

## Development stages

### I0-PROBE — first physical path

Mechanically trace the required acid-test chain:

```text
anonymous physical arrival
→ upstream local activity
→ M0 correspondence activity
→ M1 boundary-role activity
→ M2 causal-direction activity
→ M3 event organization
→ M7 learned initiation
→ existing recurrent computation
→ M8 physical closure and outward crossing
→ ordinary downstream physical return
→ M6 differential consequence activity
→ M5 plasticity allocation
→ M4 persistence/pressure
```

Start at the first absent edge. Add only the smallest allowed physical bus or
scheduler connection, freeze it, and retry the unchanged chain.

Stop if:

- more than one scientifically plausible physical wiring exists;
- a structured fixture must be reconstructed;
- a semantic primitive would enter the bus/scheduler;
- a frozen mechanism must change;
- an input required by a mechanism has no physically derivable representation;
- the addition is a cognitive representation rather than integration physics.

### I0-MICRO — continuous two-cycle learning

On two blank instances with fresh namespaces, deliver one continuous physical
stream containing at least two naturally separated cycles plus intervening
activity. Do not expose cycle boundaries.

Require:

- ordinary activity reaches every M0--M8 mechanism through physical paths;
- initiation and closure arise without start/finish calls;
- at least one outward crossing occurs only after physical closure;
- returned downstream activity causes an existing M6/M5 update;
- use strengthens and non-use/pressure weakens existing M4-governed structure;
- no `begin_episode`, `end_episode`, explicit temporary erase, or terminal
  supervision executes;
- pause/resume at a work bound is exact;
- complete-state replay is exact;
- fresh identities/layouts transfer.

### I0-GATE — self-contained continuous organism readiness

Use 3--5 blank instances and fresh continuous streams with identity, layout,
timing, ordering, overlap, distractor, delay, blocked-path, stale-path, and
capacity variation.

Conjunctively require:

1. blank state contains mechanisms but zero childhood/world content;
2. only anonymous physical arrivals enter;
3. all M0--M8 mechanisms are physically reached and causally used;
4. no experiment fixture constructor runs;
5. no semantic lifecycle/reset/erase path runs;
6. continuous activity can span multiple evaluator-observed cycles;
7. closure/emission is physical and naturally quiescent;
8. downstream physical return changes future learning through M6/M5;
9. M4 governs persistence and disappearance continuously;
10. work-bounded pause/resume equals uninterrupted execution;
11. snapshot/restore is exact;
12. complete and permanent fingerprints are allocation-independent;
13. evaluator-only inspection has zero causal path;
14. fresh identity/layout transfer holds;
15. frozen M0--M8 and SSA0.3 conformance replays remain exact;
16. source/dependency audits find no semantic integration representation.

## Controls

At minimum:

- no physical arrival → no initiation;
- subthreshold arrival → no learned initiation;
- missing closure activity → no crossing;
- blocked/stale route → cannot execute or cross;
- downstream activity without an eligible active trace → no M6 update;
- immediate activity outside the established delay relation → no M6 update;
- equal/shuffled consequence histories → M6 abstains as already established;
- no recurrence → no persistence advantage;
- continued non-use/pressure → eventual deallocation;
- activity arriving after SSA0.3 closure → physically visible but choice-inert;
- exact complete-state duplicate → exact future;
- namespace, handle, allocation, and layout permutation → physical relation
  preserved;
- evaluator removed or labels changed → causal execution exact.

## Positive classification

I0 development readiness supports only:

> Retained physics plus the authoritative M0--M8 mechanism suite can be
> connected by a semantic-free anonymous event bus and continuous scheduler
> into a blank self-contained organism that learns and emits without
> experiment-built episodes or semantic lifecycle control.

Only after a separate definitive authority matrix passes may the resulting
artifact be named `Frozen Organism v1` without qualification and H1 become
eligible.

## Negative classifications

- `I0-A`: a unique physical bus/scheduler completion is development-ready;
- `I0-B`: existing inputs are physically derivable, but multiple lawful
  integration topologies remain scientifically ambiguous;
- `I0-C`: at least one mechanism requires a fixture field that cannot be
  derived from anonymous physical activity without a new cognitive
  representation;
- `I0-D`: integration is possible only with semantic lifecycle/reset/credit
  control;
- `I0-E`: composed continuous dynamics fail even though every required
  physical edge exists.

Freeze the observed classification. Do not optimize for `I0-A`.
