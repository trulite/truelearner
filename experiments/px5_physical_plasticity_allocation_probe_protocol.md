## Frozen PROBE matrix

The PROBE contains exactly four fresh deterministic cells with namespaces
`0x5_5000_0000 + cell * 0x0100_0000`. Cells cross normal/mirrored positions and
normal/reversed CELL allocation. Each is executed from blank state and then
repeated from an independently constructed byte-identical blank state.

Each cell contains one recurring useful two-CELL neighborhood and four
one-occurrence distractor neighborhoods. All structural variation is created
only by the unchanged generic local opportunity law.

The exact physical schedule is:

1. at tick `0`, ordinary external activity fires every neighborhood source;
2. at tick `2`, only the useful source receives ordinary returned activity;
3. at tick `20`, pressure has removed return-free distractor variation and the
   useful source is tested and returned at tick `22`;
4. the useful edge is then withheld until ordinary pressure physically removes
   it;
5. fresh useful-source activity immediately receives generic local variation,
   traverses it, and receives timely return two ticks later;
6. a read-only evaluator clone reverses useful/distractor observation order and
   labels after execution; it has no mutation surface and must leave the full
   physical fingerprint and all liveness/resistance observations unchanged;
7. a separate blank return-free recurrent control fires the same local source
   only after each eligibility window and must not retain reusable structure.

CELL identities, physical origins, placements, and insertion order are fresh
per cell. The useful and distractor words exist only in evaluator output.
