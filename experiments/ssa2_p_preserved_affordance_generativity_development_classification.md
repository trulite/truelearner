# SSA2-P preserved-affordance generativity — development handoff

Status: **Classification A — conditional long-trajectory generativity**.

This is not a full SSA2 claim and does not make SSA1 positive. It establishes a
narrow compositional capability of unchanged Frozen Organism v1 when ordinary
development has already preserved multiple executable affordances.

## Claim supported

> Frozen Organism v1 can produce multiple different, structurally valid long
> trajectories from different lawful transient histories when ordinary
> consequence-driven development leaves multiple local continuations physically
> executable.

The organism has no RNG, sampler, probability representation, generative
decoder, or between-step route chooser. Each complete trajectory is one
CELL/ARROW/SPIKE propagation through a connected physical world.

## GATE result

Six fresh identity/layout/mirror cells each developed from blank under frozen
SSA1 World B experience:

```text
equivalent ordinary consequences
        -> learned live supporters [4,4]
        -> both continuations executable
```

Each cell then executed 64 fixed transient histories through a depth-32 physical
transition graph.

```text
valid length-32 trajectories       384 / 384
duplicate-exact trajectories       384 / 384
naturally quiescent                 384 / 384
distinct trajectories per cell      64 / 64
distinct trace fingerprints/cell     64 / 64
both physical sides at every layer    6 / 6 cells
identical permanent substrate          6 / 6 cells
```

The evaluator supplied all transient spike timing before propagation and only
decoded fired physical identities after the queue drained. No state or route
was selected by the harness during execution.

## Structural controls

All six cells passed:

- ordinary matched `[4,1]` development collapsed all 64 histories to exactly
  one physical-side trajectory;
- a physically blocked continuation could not win; the other executable side
  carried the path;
- removing the realized effect-to-next-state arrow terminated the trajectory at
  that layer, with no downstream teleportation;
- duplicate evaluator handles for one physical effect did not count as multiple
  affordances;
- handle permutation changed only evaluator names, not the physical path;
- exact permanent and transient replay was exact;
- fresh occurrence identities, reversed allocation, layout permutation, and
  full physical mirror preserved the relations.

These controls distinguish physical trajectory composition from counting
labels, calling a decoder, or replaying a stored sequence.

## Interpretation boundary

The 64 deterministic history words deliberately differ in which physical side
receives pre-closure support at each layer. Therefore `64/64` path diversity is
not evidence that the organism invents its own transient variation. The result
tests whether such lawful physical differences can compose through a learned
affordance landscape into long valid trajectories without an explicit generator.

The supported architecture statement is:

```text
ordinary development preserves [4,4]
        +
different lawful transient microhistory
        +
deterministic pre-closure competition
        ->
different valid length-32 physical trajectory
```

The matched `[4,1]` result also connects directly to SSA1's limitation: once
development removes executable multiplicity, transient history alone cannot
recover trajectory diversity.

## Immutable v1 negative

PROBE v1 is preserved as a development-invalid negative. It produced 16/16
valid trajectories and 8/8 distinct paths per cell, but protocol v1 assigned
the first six layers from six direct history bits while testing only histories
`0..7`. Bits 3–5 were identically zero, making the required two-side coverage
at every layer mathematically impossible.

Protocol v2 was frozen before new evidence. Its sole change cycles the fixed
history bits modulo `log2(history_count)`. It changed no learner, substrate,
depth, history count, transition topology, timing, threshold, inhibition,
control, or pass criterion. PROBE v2, MICRO v2, and GATE v2 then passed.
