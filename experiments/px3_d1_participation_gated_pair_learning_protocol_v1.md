## Two separate questions

### D1 core: participation gating

> Given uniformly available weak physical pair candidates, is traversal of a
> candidate sufficient to gate later return-based strengthening, so a candidate
> that never traversed cannot learn merely because return reached its source?

D1 core asks only whether the organization itself participated. It does not
claim that every later arrival accepted during eligibility is genuinely causal
evidence about that participation.

### D1-R diagnostic: return provenance

> After a candidate traverses and becomes eligible, can later upstream input
> activity masquerade as downstream consequence return?

D1-R is recorded beside D1 but receives its own verdict. A negative D1-R does
not retroactively negate a positive narrow D1 result. It freezes the distinct
statement: participation attribution is solved, return provenance remains
unsolved.

## Exact physical delta from the spent PROBE

The spent PROBE created candidate opportunity->consequence ARROWs by externally
firing every opportunity. Generic proposal both created and immediately
traversed each candidate, leaving every candidate eligible before any pair
participated. This permitted a first trace input to strengthen incident
candidates.

D1 removes candidate creation from the causal chain:

- the same six unordered opportunities `AB, AC, AD, BC, BD, CD` exist
  symmetrically before experience;
- each has one ordinary opportunity->consequence ARROW with delay `2`, coupling
  `1` and resistance `1`;
- all six ARROWs are added uniformly before the schedule;
- an added ARROW has no live eligibility until its source opportunity actually
  fires and the ARROW traverses;
- no opportunity priming pulse occurs;
- there is no generic proposal, formation or reproposal claim in D1;
- the authoritative four-path PX1 normalization topology, threshold-two pair
  opportunities, consequence/context topology, shared return hub, return
  strength `3`, eligibility window, pressure period and pressure strength remain
  unchanged.

The fixture supplies possibilities, not answers. Every pair receives the same
weak dormant route before any reference exposure. The evaluator never chooses
which route exists, becomes eligible, strengthens or deallocates.

## Frozen geometry and schedule

Seeds: `2901, 2909`. Four primitive participants A/B/C/D; all six unordered pair
opportunities; raw couplings `1/2/4`; normal layout; load `0`.

For ordinary exposures:

```text
tick 2   source entry
tick 3   authoritative PX1 trace firing and possible pair firing
tick 5   candidate/context arrival at consequence
tick 6   shared consequence return reaches every pair opportunity
tick 10  first ordinary pressure boundary
tick 11  recurrent source entry
tick 12  second trace/pair firing
tick 14  second consequence
tick 15  second shared return
tick 50  fixed reuse observation after pressure gap
```

All context and shared returns are uniform. Context never creates pair
eligibility. Return broadcasts identically to all six opportunity CELLs.

The frozen resistance trajectories are:

```text
dormant + return only          1 -> 1
traversal without return       1 -> 0 after eligibility expiry
one traversal + return         1 -> 4 -> 0 after pressure gap
recurrent traversal + return   1 -> 4 -> 3 -> 6 -> 2 after gap
```

Eligibility is not added as an evaluator-visible result field. It is audited
through native candidate traversal, resistance, pressure, return, liveness and
held-out consequence behavior.

## Frozen D1 core matrix

Each seed runs fresh worlds covering:

1. `dormant-baseline`: no participation and no return;
2. `return-only`: externally fire the physically remote shared return hub once,
   broadcasting return to all six dormant opportunity sources without any pair
   traversal;
3. `a-alone`;
4. `a4-alone`;
5. `a-repeated`: two scheduled A entries serialized through actual firing;
6. `a-then-b-late`: trace firings outside the overlap window;
7. `ab-one-return`: one simultaneous A+B traversal with compatible consequence
   return;
8. `ab-recurrent-1-1`;
9. `ab-recurrent-2-1`;
10. `ab-recurrent-4-4`;
11. `ab-no-return`: one simultaneous A+B traversal with consequence return
    physically blocked;
12. `ab-recurrent-heldout-matrix`: recurrent A+B followed on exact clones by
    trained AB, crossed AD, gapped A/B and singleton A held-out uses.

D1 core passes only if:

- dormant and return-only candidates remain resistance `1` before pressure and
  all deallocate under the fixed gap;
- A alone, A(4), repeated A and late A/B fire no pair and strengthen no
  candidate;
- one A+B fires/traverses only AB, legitimate return raises AB exactly `1 -> 4`,
  and AB deallocates by tick `50`;
- recurrent A+B at all amplitudes follows exactly `1 -> 4 -> 3 -> 6 -> 2`;
- after the gap only recurrent AB remains live and reusable;
- trained AB produces one held-out consequence while crossed AD, gapped A/B and
  singleton A produce none;
- AB traversal with blocked return receives no strengthening and deallocates;
- all worlds reproduce exactly and quiesce naturally.

Any D1 core failure freezes the physical edge and stops D1. It does not
authorize threshold, pressure, timing or law adjustment.

## Frozen D1-R provenance discriminator

A separate fresh world runs:

```text
tick 2   simultaneous A+B source entries
tick 3   AB opportunity fires and its weak candidate traverses
         candidate eligibility is live through tick 7
         real consequence return is physically blocked
tick 4   late A source entry
tick 5   late A PX1 trace reaches AB while AB eligibility is live
```

Serialize the late source firing, raw traversal, unit PX1 trace firing, arrival
at AB, absence of consequence return, AB resistance/coupling-crossing history,
expiry, pressure and held-out use.

- **D1-R positive:** late upstream A does not strengthen AB; AB remains
  resistance `1` and expires/deallocates.
- **D1-R negative:** late upstream A strengthens eligible AB despite blocked
  consequence return. Freeze: participation attribution works, but target-local
  eligibility does not establish return provenance.

The D1 core verdict is computed without this discriminator. The D1-R verdict is
always reported independently; it may not be hidden inside one aggregate pass
bit.

## Serialization and controls

Every row records native scheduled entries, source firings, raw coupling and
crossings, outlet firings, unit PX1 trace firings/ticks, pair arrivals/firings,
candidate traversals and crossing impulses, consequence/context/return
activity, resistance/liveness before and after pressure, work ledgers,
persistent bytes, complete/permanent fingerprints, exact replay and natural
quiescence.

Do not infer candidate coupling from current resistance. PX0 has no coupling
getter and pressure can lower resistance without lowering coupling. Only native
candidate crossing impulses are authoritative for carried coupling.

The return-only hub is physically remote from every CELL within PX0's generic
variation radius, so its external control pulse proposes no ARROW. Before any
candidate traversal, the broadcast must cause zero local return updates to
candidate routes and zero resistance changes.

## Classification and stage separation

- **D1-A:** all D1 core rows pass. Existing traversal/eligibility/return physics
  is sufficient for participation-gated learning given weak uniform candidates.
- **D1-C:** traversed candidates can receive support, but recurrence does not
  earn reusable persistence or one exposure does not decay.
- **D1-D:** an untraversed candidate strengthens, or success requires a new law,
  field, contributor identity or evaluator-selected route.
- **D1-E:** an interpretable complete D1 matrix is materially negative.
- **D1-R+ / D1-R-:** provenance discriminator verdict, always separate.

D2 is not implemented or executed by this protocol. A positive D1 core permits
only a separately preregistered D2 normalization diagnostic:

```text
mature AB execution
  -> ordinary outlet execution
  -> exactly one unit authoritative PX1 participation trace X
```

D2 may not know that X originated in a conjunction and may not emit A and B
again. Full recursion `X+C -> Y`, MICRO reversal, autonomous candidate
formation/reproposal and PX3 authority remain later independent questions.
