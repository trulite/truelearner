## Preregistered E0-A mechanism

Each episode exposes an interleaved flat stream of fresh spikes plus sparse
local precedence and directed physical-propagation edges. E0 enumerates
ordinary candidate occurrence triples from those relations; the harness does
not supply a triple or membership. A candidate is described only by its
relative temporal-relation matrix and relative propagation-relation matrix.
The candidate proposal that fires receives an ordinary binary consequence.

Persistent state is a compact table of anonymous **relation-shape** evidence:
relative temporal matrix, relative propagation matrix, strength,
success/failure counts, and maturation/contradiction state. It may not retain
episode membership, occurrence IDs, absolute layout, or a temporary event.
Generic proposals receive `+2/-1`; a relation shape matures at strength `6`
after at least three successes and zero failures. Two consecutive
contradictions invalidate it and reopen generic proposal. No fallback exists.

After a mature relation shape matches exactly one current candidate, E0 emits
a temporary `EventRelations` value containing:

- membership: exactly the three current occurrence handles selected by E0;
- the selected members' complete relative temporal-precedence matrix;
- their complete relative directional-propagation matrix;
- member-local temporal ranks derived during E0 formation;
- member-local propagation ranks derived during E0 formation;
- member-local attachment-equivalence bits already present in E0 temporary
  state.

The temporary value owns no supplied semantic slots. Its canonical member
order is the lexicographically minimal ordering under the two relation
matrices, with ambiguity causing abstention. Canonicalization is part of E0-A,
not the serializer. It uses no occurrence numeric value, allocation order, or
absolute layout. The value is destroyed at episode end. Persistent state
retains only the relation shape.

E0-A succeeds only if temporary state itself contains the membership and all
relations needed by E0-B, while persistent retained episode membership and
occurrences are exactly zero.

## Preregistered E0-B serializer

E0-B accepts only an already-created `EventRelations`; it has no access to the
raw stream, unselected occurrences, evaluator state, persistent learner, or
consequence. It performs a single fixed field copy into the frozen DS1
`Neighborhood` representation:

| Frozen DS1 field | Existing E0 temporary provenance |
|---|---|
| `pair[0].identity` | canonical member 0 occurrence handle |
| `pair[1].identity` | canonical member 1 occurrence handle |
| `witness.identity` | canonical member 2 occurrence handle |
| each `position` | that member's relative propagation rank |
| each `tick` | that member's relative temporal rank |
| each `window` | that member's attachment-equivalence bit |

Every destination field must have exactly one source field and every source
must already exist before the serializer call. E0-B may not scan, choose
membership, choose a pair or witness, form a window, compare raw relations,
canonicalize, read evaluator truth, or recompute a relation. Serialization is
performed once per successfully formed event.
