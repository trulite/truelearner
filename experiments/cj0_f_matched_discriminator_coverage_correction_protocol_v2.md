## Exact correction surface

Only the four defects frozen in the GATE v1 audit are corrected:

1. `BURST_4` enters four emissions from one physical source down one live
   source-to-locus path at consecutive ticks 0,1,2,3.
2. `BLOCKED_LATE_RETURN` performs a genuine traversal, advances naturally
   beyond the eligibility window to tick 5, then delivers ordinary return
   activity to the physical source at tick 6. The return must not strengthen
   the expired route.
3. `TIMING_TRANSFER` executes establishment at train spacing 0,2,4, delivers
   return only when traversal created eligibility, advances to fresh base tick
   10, then executes held-out spacing -1,0,1,2,3,4,5 in the same instance.
   Training work/effect and held-out work/effect are serialized separately.
4. `CONTEMPORARY_REVERSAL` begins with A->B and C->D physical routes, executes
   genuine A+B/C+D, lets both unsupported old routes fully deallocate, fires A
   and C to generically bootstrap only nearby crossed A->D/C->B routes,
   establishes both crossed routes with ordinary return, then executes
   held-out crossed reuse. Old/new support and learning, deallocation,
   reacquisition and reversal work are serialized.

The fixed pressure-boundary observations at ticks 8,10,11,13,14,16 are made
in the reversal world after held-out reuse. They are observations, never a
candidate-specific rescue schedule.
