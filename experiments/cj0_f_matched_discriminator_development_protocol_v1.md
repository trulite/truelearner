## Question and decision rule

The question is whether frozen CELL-coincidence (CJ-E) and frozen
ARROW-gated coincidence (CJ-B) differ in a lawful physical world under one
matched matrix. No mechanism development is authorized.

A candidate is scientifically sufficient only when it:

1. responds to genuine current co-participation and supports held-out reuse;
2. rejects matched single-source repetition and a matched strong singleton;
3. attributes return and strengthening only to physically traversed eligible
   structure in dense topology;
4. closes naturally outside its live window, transfers across the timing
   matrix as declared by its frozen law, reverses after full deallocation, and
   supports level-free three-step recurrence without runaway activity.

Select a candidate only if it remains sufficient while the other violates a
genuine physical requirement, or if it covers every requirement with strictly
fewer physical assumptions. Speed alone cannot select. If both pass, report
multiple valid minimal substrates / implementation-hardware fork. If both
fail, freeze the shared boundary. If physical interpretation of a failing row
is ambiguous, report ambiguity and stop without changing either candidate.

## One common physical world schema

Every paired row is constructed independently for B and E from the same
immutable `WorldSpec`. The spec contains only physical quantities:

- row identifier, seed, stage, family, layout and mirror;
- CELL physical identity, position, region, threshold, resistance;
- ARROW endpoints, delay, phase, coupling, resistance and insertion order;
- external SPIKE tick, phase, physical origin, target and impulse;
- return topology, ordinary pressure horizon and observation horizon.

The evaluator may retain source/path provenance solely as expected-world
truth for scoring. It is never passed as a contributor label, pair identity,
relation key, semantic flag, historical member list, or candidate branch.
The B and E laws receive identical serialized specs and schedules. Candidate
outputs are written independently, then joined by `row_id`; no candidate
output controls later activity.

The canonical conjunction world has two threshold-1 emitters, a threshold-2
coincidence CELL, an ordinary return CELL, and a cross-region effect CELL.
Both candidate instances receive the same nearby alternative arrows and the
same return activity. Mature coupling means resistance 30/coupling 2; weak
coupling means resistance 3/coupling 1. Threshold sweeps use 2, 3, and 4.
Spacing sweeps use `-1, 0, 1, 2, 3, 4, 5` ticks relative to the trigger, with
phases breaking ties but never encoding identity. Loads are `0, 4, 12` nearby
distractor CELL/ARROW pairs. Sparse/dense allocation uses `2/6` symmetric
eligible incoming arrows. Mirrors negate positions and reverse insertion
order without altering activity marginals.

### F1 -- same-source bursts

For weak and mature coupling, execute:

- `AA_SAME_TICK`: two equal emissions with one physical origin down one path;
- `AA_SPACING_d`: repeated A at every preregistered spacing `d`;
- `AA_BURST_4`: four A emissions at unit spacing;
- `AA_TWO_EMISSIONS_ONE_PATH`: two emissions on one physical ARROW path;
- `AB_DISTINCT_d`: equal A and B emissions on distinct paths at each spacing.

The total impulse and event count of each A+A row is matched to its A+B row.
Genuine A+B must produce conjunction/effect and held-out reuse inside the
candidate's physical window. A+A is a false conjunction if it produces the
same learned conjunction/effect without distinct physical co-participation.

### F2 -- amplitude versus contributor multiplicity

At every threshold/coupling stratum, match total impulse as closely as integer
physics permits:

- `ONE_STRONG`: one arrival carrying the full impulse;
- `TWO_WEAK_DISTINCT`: two half arrivals from distinct physical paths;
- `TWO_WEAK_SAME`: two half arrivals from one physical source/path;
- `WEAK_STRONG_DISTINCT`: asymmetric distinct arrivals summing to the same
  impulse.

No contributor label is supplied. Record locus firing, transmission/effect,
eligibility, return support, proposals, false conjunction and held-out reuse.
`ONE_STRONG` and `TWO_WEAK_SAME` must not substitute for genuine contributor
multiplicity. Integer rounding is serialized and rows with unequal total
impulse are comparison-ineligible rather than rescued.

### F3 -- dense return topology

Construct symmetric eligible arrows around the same target and vary:

- sparse/dense allocation;
- physically traversed/nontraversed alternatives;
- direct/crossed return;
- distractor load `0/4/12`;
- normal/mirror layout and forward/reverse insertion order.

Return is ordinary physical evidence and is never labelled incorrect.
Measure per-arrow eligibility consequences, resistance/coupling change,
accidental conjunction/effect, old self-evidence, stale-generation behavior,
reversal cost, full deallocation and fresh reacquisition. A nontraversed or
stale arrow strengthening is attribution failure; a traversed arrow receiving
physical return is not.

### F4 -- timing transfer

Establish separately at training spacings `0, 2, 4`, then execute held-out
spacing continuously at `-1, 0, 1, 2, 3, 4, 5`. Classify each held-out point
as before/same/inside/edge/outside/after natural closure from serialized
physical state, not expected candidate identity. Record firing/effect,
support, residual transient state, closure tick, tolerance width,
brittleness, replay and quiescence. No train-window-specific rescue is
allowed.
