## Formation without priming self-evidence

All six unordered A/B/C/D trace-pair opportunities exist symmetrically. Each
ordinary threshold-two opportunity O sends one unit to its pair-local candidate
source P. Every P has threshold two and exactly one potential consequence cell
at physical distance one. No P->effect candidate ARROW exists initially.

At every experience the harness supplies the same external unit background to
all six P cells after O's internal unit arrival:

```text
inactive pair:
  background 1 -> P state 1 -> no firing -> no proposal

active joint pair:
  O 1 + background 1 -> P fires on the external arrival
  -> unchanged PX0 generic local proposal creates fresh P->effect ARROW
  -> the new candidate immediately traverses
```

Because the external background arrival is the threshold-crossing arrival,
PX0's existing `propose_local_arrows` path performs formation. Background is
identical at all six P cells and never names the scheduled pair. Candidate
creation is physically gated by actual pair co-participation.

This replaces the old PX3 priming fixture. No candidate exists or is eligible
before P actually fires. No evaluator inserts, revives, selects or deletes an
ARROW.

## Integrated attribution geometry

Each formed P->effect candidate has PX0 distance-one delay, coupling one and
resistance one. The remaining route is R3's existing physics:

```text
P executes and candidate traverses
  -> one normalized P participation trace
candidate + uniform context execute effect
  -> one normalized effect participation trace
P trace + effect trace + ordinary global return
  -> threshold-three attribution M
M -> P carries one unit
  -> eligible candidate strengthens
  -> P(threshold 2) remains subthreshold
```

There is no effect/relay-to-P edge. Candidate delay and context delay are one;
P trace is delayed one into M. For an episode beginning at tick `s`:

```text
s     primitive sources
s+1   primitive traces/O; uniform P background; active P fires/proposes
s+2   candidate + context fire effect; normalized P trace fires
s+3   normalized effect trace + delayed P trace + global return fire M
s+4   unit attribution reaches P, credits candidate, does not fire P
```

The distance-one timing is required so two pair episodes can occupy separate
trace windows and both complete attribution before the first tick-10 pressure
edge. It is fixed before evidence and is not tuned per pair or phase.

## Why AB and CD are temporally separated

Simultaneous A+B+C+D traces would physically overlap at all six pair
opportunities and lawfully create a six-edge clique. MICRO is testing two
events, not one four-part event, so AB and CD occupy distinct trace windows.
The same separation is used for AD and BC after reversal.
