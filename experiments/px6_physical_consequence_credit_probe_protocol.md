## Frozen PROBE

Run eight physical presentations in each of six fresh worlds, with 14 ticks
between presentations. Two weak reserve-3 arrows compete under ordinary
pressure. A traversed arrow reaches a downstream cell; the same downstream
firing produces an outward crossing and, when physically connected, ordinary
return through a two-input trace cell to the arrow's source. The harness may
choose external arrivals, construct topology, and observe state, but no
harness value enters `PlasticSubstrate`.

| world | traversal | downstream firing | return destination | expected retained arrows |
|---|---|---|---|---|
| left | left | matched both sides | own active source | left only |
| right | right | matched both sides | own active source | right only |
| both | both | both | each own active source | both |
| correlation | neither | matched both sides | both inactive sources | neither |
| crossed-return | left | matched both sides | right inactive source | neither |
| no-return | left | matched both sides | physically disconnected | neither |

The correlation world deliberately has downstream firing and physical return
without preceding candidate traversal. The crossed-return world deliberately
has traversal and return in the same presentation but no local coincidence on
the participating structure. Thus occurrence, timing, magnitude, and global
presence cannot serve as covert outcome signals.

Every world is executed twice from a blank substrate with the same physical
identities. Exact complete-state replay is required. The result serializes,
per side, traversal count, downstream firing count, return arrivals,
resistance before/after, liveness, held-out outward execution, quiescence,
work, persistent bytes, and fingerprint.

## Pass and stopping rule

All `6/6` worlds must satisfy their frozen retained-arrow vector; every
expected participant must traverse eight times; both downstream cells must
fire eight times; return counts must match physical topology; retained arrows
must execute on fresh held-out activity; nonretained arrows must not; all runs
must quiesce; and duplicate reports must be exact.

Failure is frozen without rescue or rerun. Success is a no-new-mechanism
PROBE positive and makes a separately preregistered MICRO eligible. It creates
