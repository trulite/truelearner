## Ordered path-existence checks

Each arm reports its first collapse in this order:

1. **Source/information audit** -- exact ancestry and parts hashes; no
   forbidden boundary, correctness, lifetime, or evaluator flow.
2. **Single lifecycle** -- no temporary/permanent structural tier; the same
   local record/update law can strengthen, weaken, execute, and disappear.
3. **Useful persistence** -- both recurring lawful signatures remain usable
   on relabelled return and reconstruct exact M3 spans/consequences.
4. **One-off removal** -- all eight one-off signatures physically disappear,
   not merely become inactive in retained allocations.
5. **Contradiction response** -- the contradicted signature cannot execute as
   a stale learned path; generic reopening remains functional.
6. **Relearning** -- one removed signature can be acquired again through the
   identical ordinary path with no reset or special allocation mode.
7. **Economy/lifecycle** -- final persistent bytes are below the raw keep-all
   control; occurrence-local workspaces return to zero; all work is counted.
8. **Determinism** -- an exact duplicate is byte-identical.

PROBE is conjunctive within an arm. There is no percentage threshold.

## Frozen controls

1. **Keep-all control:** preserves return but retains every one-off signature;
   it must fail removal/economy.
2. **No-recurrence control:** shuffle local signature adjacency while keeping
   event counts and work fixed; it must not preserve the useful records as if
   they had recurred.
3. **No-disuse/pressure control:** suppress only the lawful weakening input;
   it must over-retain at least one one-off record.
4. **No-contradiction control:** suppress only contradiction input; the stale
   learned path must remain more available than in the intact arm.
5. **Boundary-label probe:** change external request/finish scheduling while
   preserving organism-visible spikes; the lifecycle snapshot must be exact.

Controls diagnose causal paths and do not contribute extra pass opportunities.
