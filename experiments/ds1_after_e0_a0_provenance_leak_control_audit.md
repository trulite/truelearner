# Frozen DS1 after DS-E0 + DS-A0 provenance, leak, and control audit

## Exact cumulative provenance

The primary A0 path does not call the A0 fixture. For each support presentation
and target presentation, frozen E0 first learns and forms an actual
`EventRelations` from the current raw episode. A composition-only format export
then copies, in order:

- every raw spike occurrence and tick;
- every observed raw propagation endpoint pair;
- all three formed event members;
- all nine relative-temporal fields; and
- all nine relative-propagation fields.

The A0 composition scope maps those same occurrence values one-to-one to
temporary CELL indices, copies ticks and observed propagation, and copies the
formed relation matrices into `EventFrame`. It creates no executable ARROW from
raw observation. Frozen A0 plasticity alone installs any executable
CELL/ARROW route, before the bridge. The target evaluator membership check is
post-hoc and is not read by the export or A0 installer.

Across MICRO seed 100 and GATE seeds 100..104, all pulse counts, propagation
counts, members, temporal fields, and propagation fields round-tripped exactly.
Acquisition and target occurrences were disjoint. Each seed produced five
learned E0 shapes, four temporary formed relations (three support plus one
target), one exact E0-B serialization, and one read-only frozen DS1 consumption.

## Actual route and bridge inventory

For every seed, the exact E0 target produced:

| Inventory | Count |
|---|---:|
| A0 generic supported templates | 1 |
| executable event roots before A0 formation | 0 |
| roots installed by frozen A0 plasticity | 1 |
| installed route CELLs / ARROWs | 3 / 2 |
| opaque bridge handles / unique real roots | 1 / 1 |
| ordinary pre-choice physical effects / distinct effects | 1 / 1 |

The one handle is a mechanical reference copy of the one installed root. The
required multiplicity is greater than one, so handle permutation, DS1 mutable
choice, and selected execution are causally blocked. They are not reported as
successful controls. The permutation test itself enforces the stronger rule
for any future reachable two-route inventory: the same opaque choice index must
select different fingerprints after reversal, and both fingerprints must
already belong to their respective pre-choice inventories.

## Leak and negative audit

Mechanically scanned persistent state has zero fields containing occurrence
identity, concrete destination, filler, or evaluator tokens. The integrating
export/mapper/choice/execution bodies have zero expected-action, correct-route,
opcode, or handle-switch translation sites. Occurrence values exist only in
fresh temporary episode exports and are not retained by frozen E0, A0, or DS1
persistent learners.

The focused mutation suite proves:

- each ordered stage 0..11 becomes the exact first collapse when independently
  mutated false;
- an added post-execution observer changes only the consequence-observation
  edge inventory;
- an added executor consequence site changes only the parent consequence-path
  inventory;
- an added frozen update call changes the apply-call inventory; and
- equal selected fingerprints fail the strengthened permutation predicate.

No new consequence path, DS1 update, evaluator adapter, action opcode,
post-action truth, stable token, isolated fixture, or DS2+ surface exists.
