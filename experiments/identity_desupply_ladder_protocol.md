# Identity de-supply ladder preregistration

Protocol identifier: `identity-desupply-ladder-v1`

Status: umbrella ladder frozen after FFS-SAME0 implementation freeze and
before any definitive FFS-SAME0 execution or result.

## Purpose

This protocol preregisters the complete developmental path for replacing
supplied filler equality with learned mature substrate structure:

```text
FFS-SAME0
learn correspondence instead of supplying SAME
        |
        v
CS0a
compile mature learned correspondence
        |
        v
CS0b, only if the frozen trigger is met
amortize repeated temporary grounding
        |
        v
FFS-SAME1
use compiled learned correspondence as ordinary level-blind substrate
        |
        v
IP0
final identity-prior economics
```

The ladder applies one already-observed developmental pattern deliberately:

```text
general learned mechanism
        -> functional but expensive
        -> repeated successful use
        -> consolidated local path
        -> reuse and amortization
        -> ordinary substrate input to the same kernel
```

The ladder does not force cross-process closure. Learning, retrieval, and
decision remain independently `UNAVAILABLE` until their real computation
naturally executes through the anonymous substrate without an adapter.

Allowed throughout:

```text

Forbidden throughout:

```

Evaluator truth remains type-separated below the organism boundary. Every new
observation receives a fresh occurrence identity. All FFS-SAME0 source and
dynamic leak audits remain mandatory in every downstream capability gate.

### No level or economic oracle

No organism-visible state or path may contain or branch on:

```text

process label

```

Levels, prices, traces, ownership, and economic retention are evaluator-only.

### One lifecycle

The allowed lifecycle is always:

```text
generic anonymous inference
        -> repeated successful use
        -> ordinary consolidation
        -> compiled role-relative path
        -> local execution

contradiction or context violation
        -> invalidate compiled path
        -> reopen generic inference
```

No evaluator fallback, hidden cache, supplied compiler target, process-specific
executor, or new correctness mechanism may be added.

### Parent-relative promotion

Every recursive promotion earns itself against its immediate retained parent:

```text
L(k+1) versus L(k)
```

Never against L0 after the first edge. A profitable deeper structure cannot
subsidize a failed intermediate structure.

### Experimental discipline

Each capability gate receives MICRO, GATE, and one write-once DEFINITIVE mode.
Development writes no result artifact and supports no claim. A definitive
command may run exactly once from its frozen implementation tag. Frozen parent
definitive artifacts are consumed read-only and are not regenerated as
regression tests unless their frozen source was changed.

Every downstream definitive capability gate uses frozen seeds `0..7` and at
least sixteen fresh held-out episodes per independent condition. Development
uses disjoint seeds and may use smaller populations and episodes. Independent
cells remain deterministic and single-threaded; parallelism is across cells.

No downstream capability may be implemented before its prerequisite outcome
and trigger are satisfied. No rescue mechanism may be inserted between the
gates in this protocol.

## Conditional Gate 2 — CS0b: temporary grounding amortization

CS0b is conditional. Preregistering it does not require running it.

### Frozen trigger audit

After a positive definitive CS0a outcome, hold all code and assets fixed and
measure within-episode use counts:

```text
U = 1, 2, 4, 8, 16
```

For each U, attribute work to compiled activation, temporary binding/route
installation, ordinary use, effect delivery, and cleanup. Define:

```text
residual repeated-overhead slope =
    (overhead(U=16) - overhead(U=1)) / 15

grounding slope =
    (temporary binding + installation work at U=16
     - temporary binding + installation work at U=1) / 15
```

CS0b opens only if both are true:

1. `grounding slope > 0`;
2. grounding accounts for at least half of the positive residual repeated-
   overhead slope.

Otherwise CS0b is recorded `SKIPPED: trigger absent` and FFS-SAME1 opens
directly. This skip is a preregistered outcome, not a post-hoc protocol change.

### CS0b question

> Can one correctly grounded correspondence be reused for multiple valid
> operations within its temporary lifetime instead of being re-grounded on
> every invocation?

Allowed lifecycle:

```text
infer or compile role-relative correspondence
        -> bind current occurrences once
        -> use at U declared safe operations
        -> erase at episode/context boundary
```

Grounding may not survive into a fresh episode. A persistent compiled rule may
survive; its concrete temporary occurrence bindings may not.

### CS0b matrix and controls

Use `U = 1, 2, 4, 8, 16` with:

```text
stable within-episode target
fresh occurrences at the next episode
target change midway through the same episode
causal-context change midway through the same episode
interrupt and re-entry at every declared safe boundary
stale binding
missing and ambiguous correspondence
historical context return
```

For target change `a<->b` to `a<->c`, the grounded path to `b` must cease before
the first `c`-scoped effect. No evaluator reset or identity correction is
allowed.

### CS0b pass

Positive iff every definitive seed preserves exact traces and perfect
invalidation while the parent-relative per-use temporary-grounding slope is
strictly lower than repeated CS0a grounding. Supplied-SAME parity is not
required.

### CS0b stopping rule

```text
trigger absent -> skip and open FFS-SAME1
trigger present, CS0b negative -> freeze negative; stop identity branch
trigger present, CS0b positive -> freeze and open FFS-SAME1
```

## Gate 4 — IP0: identity-prior economics

IP0 is accounting only. It adds no learner, correspondence rule, compiler,
grounding path, executor, maintenance behavior, or invalidation behavior.

It consumes the frozen actual artifacts from:

```text
supplied-SAME FFS0
generic learned FFS-SAME0
compiled CS0a
CS0b when run, or the frozen SKIPPED decision
full mature FFS-SAME1
```

### Physical accounting

For each workload and each learned asset ownership boundary, report:

```text
A = generic correspondence acquisition
C = compilation acquisition
G = optional grounding-amortization acquisition
I = installation
S = incremental persistent bytes
M_use = maintenance per use
M_time = carrying/maintenance per horizon
W_supplied(d) = supplied-SAME mature runtime
W_generic(d) = FFS-SAME0 mature runtime
W_compiled(d) = FFS-SAME1 mature runtime
```

The whole-stack delta against supplied SAME is:

```text
Delta(H,d) =
    A + C + G + I
  + carrying(S,H)
  + H * (W_compiled(d) + M_use(d) - W_supplied(d))
```

Report blank-start ownership and incremental already-owned views separately.
One asset acquisition is charged once only when the exact persistent asset
instance is reused across workloads or recursive distances. Separately learned
lookalikes remain separately charged.

Zero carrying price is primary. Secondary prices remain `0, 1, 10, 100, 1000`
millionths of work per byte-use. Exact integer arithmetic and exact ceiling
break-even are authoritative. Reuse horizons are analytical, not simulated.

### IP0 classification

IP0 must select exactly one physical classification per workload:

#### Case 1 — execution-prior advantage

```text
W_compiled(d) > W_supplied(d)
```

No horizon breaks even against free supplied SAME.

Eligible interpretation:

> Supplied filler equality is de-suppliable functionally but remains an
> economically valuable execution prior.

#### Case 2 — developmental-prior advantage

```text
W_compiled(d) == W_supplied(d)
```

The mature per-use paths reach parity, but positive acquisition remains a
constant historical cost. No finite horizon strictly repays a free supplied
prior; average cost approaches parity asymptotically.

Eligible interpretation:

> Supplied filler equality is primarily a developmental prior; learned and
> compiled structure reproduces its mature computational function at the same
> execution cost after paying acquisition.

#### Case 3 — learned specialization advantage

```text
W_compiled(d) < W_supplied(d)
```

Finite break-even is possible and must be computed with complete acquisition,
installation, storage, carrying, and maintenance.

Eligible interpretation only after finite whole-stack break-even:

> Learned correspondence specialized beyond the generic supplied prior for the
> tested environment and repaid the cost of doing so.

No numerical tolerance converts a positive delta into parity. Physical work is
integer-exact. Charged scenarios remain secondary.

## Broader use

This ladder preregisters a reusable scientific recipe, not automatic permission
to remove other primitives:

```text
supplied prior
    -> structural ablation
    -> generic learned replacement
    -> functional recovery
    -> compiled repeated replacement
    -> conditional temporary grounding amortization
    -> reintegration into the full system
    -> whole-stack economics
```

Any later application to boundary roles, causal direction, queue semantics,
finish, proposal physics, terminal credit, or another prior requires its own
frozen protocol. Some of those may be irreducible substrate physics. The
identity ladder supplies the method for distinguishing logical necessity,
learnable expense, compilable maturity, and complete economic replacement; it
does not prejudge the answer.
