## Common question and evidence independence

Can physically distinct execution and learning routes accept genuine completed
downstream return while rejecting renewed upstream drive, without semantic
reward, credit, cause or outcome data?

Arms A, B and C use the same seeds, matched physical worlds, timings,
amplitudes, measurements and conjunctive verdict. All three implementations
must be frozen before any evidence command runs. No arm may be tuned using
another arm's result. Each arm has its own source, artifact names, immutable
implementation tag and fresh E2B sandbox.

The arms are:

- **A -- route-aware existing state:** an incoming `S -> P` traversal may
  strengthen eligible `P -> X` only when currently eligible ordinary arrows
  form a directed physical path `X -> ... -> S`. No active state is added;
  topology-search work is charged.
- **B -- compartmental return:** upstream drive targets execution cell P;
  return targets a separate ordinary neighboring compartment C. Activity at C
  may update an eligible arrow sourced at adjacent P but does not enter P's
  firing state. No arrow mode or semantic field is added.
- **C -- distinct modulatory transmission:** arrows have one of two physical
  transmission modes. Drive changes target activation but never invokes
  plasticity. Modulatory transmission may update eligible outgoing arrows at
  the target but does not change activation. The mode carries no valence or
  outcome identity.

## Common six-case matrix

Seeds `4101, 4109, 4111, 4127` cross insertion and reflection strata. Every
arm executes these fresh cases twice for exact replay:

1. candidate traversal plus renewed upstream drive, no world return: P may
   execute again; candidate strengthening is zero;
2. candidate traversal plus completed downstream route and timely return:
   exactly one strengthening; weak feedback does not refire P;
3. downstream return route active without candidate traversal: zero;
4. completed downstream return after candidate eligibility expiry: zero;
5. renewed upstream drive and lawful return at the same tick: exactly one
   strengthening, never two;
6. upstream execution only: P and candidate may execute; strengthening zero.

All ordinary drive and return/modulatory arrows carry unit amplitude. P has
threshold two, so paired upstream drive may execute it while a single lawful
return cannot. Candidate resistance begins at one; one lawful update is
`1 -> 4`. Ordinary unsupported-use pressure may deallocate an expired
resistance-one candidate in the late control.

## Selection measurements

Every arm serializes actual routes and firings, candidate traversal and
eligibility, resistance/coupling transitions, exact accepted/rejected update
counts, work, storage, replay and quiescence. Additionally:

- A records topology edges searched and proves no new active state;
- B records compartment activity and adjacency scans;
- C records drive/modulatory deliveries and added mode storage.

Functional validity is conjunctive and identical across arms. Selection is
then by the cheapest law satisfying:

1. all six causal controls;
2. natural quiescence and exact replay;
3. no semantic outcome encoding;
4. smallest active-state, topology, work and locality cost;
5. later PX0--PX2 successor-conformance potential.

No functional positive automatically selects a law or reopens PX3.
