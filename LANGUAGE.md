# Language

Use small words for CORE1 behavior.

## Nouns

```text
input · cell · link · path · output · outcome · strength
```

## Verbs

```text
fire · form · choose · hold · return · strengthen · reuse
```

## Core story

```text
input fires
→ links form a path
→ one path is chosen
→ output fires
→ outcome returns along the used path
→ used links strengthen
→ later input reuses the path
```

Prefer these words in code comments, current documentation, and user-facing
explanations. Use a longer technical name only when naming an exact code symbol
or preserved research artifact.

Frozen experiment records keep their original language under
`experiments/archive/academy-docs/`.
