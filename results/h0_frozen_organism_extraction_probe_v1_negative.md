## First missing edge

The first required H0 surface is blank construction. It is fixture-bound.

The authoritative event path does not construct a content-empty cumulative
learner. `ds4_event_gate` starts with a default boundary learner and immediately
acquires generated `standard_stream` histories. The request path also calls
`fixed_roles_and_program(seed)`. Treating either result as
`FrozenOrganismV1::blank(...)` would retain generated acquisition content or
supplied program structure.

The PROBE therefore stopped before extraction. It did not wrap these fixtures
in a new API.

The closure computation has the same construction problem one layer lower.
`frozen_iterable_operation()` creates a learner, generates 32 seeded chain
episodes, applies terminal supervision, and then returns the learned lookup and
feedback route. That may be legitimate frozen research machinery, but it is
not a content-empty constructor that can be mechanically renamed `blank`
under this protocol's explicit ban on generated acquisition episodes and
seed-derived initial state.

## Scientific interpretation

M0--M8 remain authoritative for their preregistered cumulative matrices. This
negative does not reinterpret any de-supply result.

It narrows what those results established:

> The cumulative matrices compose learned mechanisms inside experiment-built
> developmental and execution fixtures; they did not yet establish a single
> content-empty, continuous organism object that accepts anonymous physical
> arrivals directly.

Producing that object now requires at least one new integration representation:
a lawful mapping from continuous anonymous CELL/ARROW/SPIKE arrivals into the
currently separate event, correspondence, role, credit, allocation, lifetime,
and closure mechanisms. It also requires replacing externally delimited
temporary-state erasure with ordinary continuous dynamics.

Those choices are architecture/integration research, not semantic-preserving
cleanup.
