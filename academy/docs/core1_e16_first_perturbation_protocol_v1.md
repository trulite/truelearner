# CORE1-E16 — first perturbation protocol v1

## Status

Paired new-affordance discriminator rooted at CORE1-B E15-C result `d203793`.
The accepted organism/runtime remains unchanged. Self-trigger and spontaneous
variation exist only in their isolated evaluator arms and gain no authority

## Question

When an unresolved live context has no learned action preference, what is the
smallest addition that produces action number one?

## Frozen base

Reuse the E15-C unresolved spatial context, CORE1-B profile, four opaque
actions, eight balanced action/usefulness permutations, generated contact
topology, route lifetimes, thresholds, consequence path, PQLC, two-consequence
budget, Reference/replay/Production comparison, and natural quiescence gates.

## Zero-initiation control

Present the unresolved context through the unchanged Academy boundary with no
babble, transient-history selection, self-trigger, or spontaneous event.
Require the retained E14 observation: no action, update, or Modulatory return;
natural quiescence.

## Arm S — deterministic self-trigger

A live unresolved context emits one internal continuation trigger. Existing
deterministic competition resolves equal routes to the first eligible opaque
route in that seed's physical opportunity order. Every later S initiation
repeats that same route, as v21 repeated one selected continuation.

S does not inspect usefulness or consequence. It receives two fixed
opportunities, each containing four identical re-triggers. If its route causes
the world transition, one ordinary consequence is admitted for that
opportunity. Otherwise none is admitted.

## Arm V — blind spontaneous variation

At each opportunity, four blind spontaneous events visit the four eligible
opaque routes once in a deterministic replayable seed permutation. The event
has no access to usefulness, consequence, uncertainty, or future state.

Only the branch whose action physically changes the world continues to the
ordinary consequence. The second opportunity uses another preregistered blind
permutation. No sampling stops because a later probe passed.

## Fixed observations

For zero, S, and V record:

- whether a first action occurs;
- first action and attempts/ticks to first action;
- motor participations per opportunity;
- whether useful evidence occurs;
- admitted consequences, Modulatory deliveries, and material updates;
- final autonomous action without initiation support;
- useful-route coupling/resistance;
- PhysicalWork and natural quiescence.

The primary success chain is:

```text
blind first perturbation
-> useful world change
-> two ordinary consequences
-> PQLC maturation
-> autonomous useful action
```

## Interpretation

- S and V positive: both suffice; compare simplicity/cost;
- S positive, V negative: deterministic continuation is sufficient;
- V positive, S negative: equal unresolved routes require blind symmetry
  breaking beyond repeating one continuation;
- neither positive: the break lies before these initiators.

Partial seed success is reported by arm. The useful route occupies each opaque
opportunity position exactly twice, so a fixed first-route mechanism has a
preregistered `2/8` opportunity to coincide with usefulness.

## Prohibitions

No runtime-law change, useful-action lookup inside either initiator, adaptive
curriculum, train-until-probe-success, epistemic/history preference, reward,
benchmark answer, route-target coupling, post-observation repair, or authority
advance.
