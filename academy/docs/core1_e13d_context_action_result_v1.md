# CORE1-E13D — context-to-action chain diagnostic result v1

## Classification

CORE1-A, CORE1-B, and CORE1-C all stop at **class B**:

> Candidate action topology appears and actually traverses, but it produces no
> motor/output crossing.

This is the first broken physical link. It is not a failure of consequence
delivery, credit, plasticity, retention, or learned re-execution, because the
world never receives an organism action from which those later stages could
begin.

## Exact chain result

Across all four contexts in all three profiles:

| Context produces physical activity | yes |

Participation remained nonzero at the later observation point. The recorded
material changes were ordinary local decay, not learning: support was not
admitted, Modulatory deliveries were zero, and plasticity updates were zero.

## Profile comparison

CORE1-A generated separate ordinary contact paths. The generated surface uses
contact-local positive and negative alternatives; some unsupported weak links
had already decayed out of later snapshots. CORE1-B and CORE1-C generated the
same signed opportunity more generically: each context had a live direct `+1`
and `-1` candidate pair, with derived contact topology also present.

The generic profiles are byte-for-byte observationally identical in E13D.
Their simultaneous opposite signed direct effects cancel at the threshold-2
motor junction; the independent babbler contributes only one remaining unit,
so the motor does not fire. CORE1-A also expresses both signs through contact
paths, and its two-link candidate route arrives later than the one-link babbler
route. It likewise never forms an executable threshold incidence.

Thus the common developmental wall is narrower than “variation failed”:

```text
context activity
→ signed candidate structure exists
→ candidate structure participates
→ candidate incidence is not executable at the motor junction
→ no outward action
→ no physical consequence
→ no selection
```

The result does not justify changing physics. It identifies a developmental
bootstrap problem at the boundary between symmetric variation and executable
action.
