## Exact physical delta

Qualified local Modulation already added the continuously remaining
`participation_level` to transient `plastic_support`. CE0 compares universal
participation quanta completed before and after that addition. Each newly
completed quantum adds one ordinary impulse to the same ARROW's coupling.

The update reads only the local ARROW's existing participation, support, and
coupling. It does not read any destination CELL field, including threshold or
activation, and does not inspect firing success, output, correctness, task,
identity path, or benchmark state.

The feature adds a causally inert `PhysicalEvent::Coupling` observation and one
unit of PhysicalWork when coupling physically changes. No new state field,
timer, ceiling, attenuation, normalization, or cycle behavior was added.
