## Decisive distinction

E20 shows that preserving traversed route material is not the same as
preserving the route-local physical condition that admits consequence into
PQLC.

The pending arrow bits remained present and kept their marked topology from
deallocation, yet the completion-rooted variation cycle allowed the earlier
context/motor return condition to disappear. The later returning consequence
therefore reached no qualifying relay: it produced zero Modulatory deliveries,
so unchanged PQLC had no event to propagate.

This is not E19's opportunity-regeneration failure. P1 repaired that. It is a
strictly narrower credit-admission boundary:

> A route-local eligibility bit on traversed arrows can preserve structure
> across completion, but structure alone does not preserve the local physical
> return condition by which consequence reaches existing PQLC.

## Why E20 stopped

The v3 stop boundary prohibited any further candidate repair after a valid P1
or P2 failure. In particular, E20 did not:

- hold relay activation across completion;
- make returning consequence inspect pending bits directly;

- store an action/episode association;

- add an unreturned OPEN self-loop.

Any of those would test a third requirement beyond the two-state composition
preregistered here.

## Retained conclusion

The two-lifetime decomposition remains useful, but E20 does not earn it as a
sufficient primitive composition. It separates a third locality question:

```text
USED-PENDING topology survives
!=
consequence has a physical route into PQLC
```

The next experiment, if any, must isolate a payload-free route-local return
condition. It cannot silently reinterpret structure protection as credit
admission.
