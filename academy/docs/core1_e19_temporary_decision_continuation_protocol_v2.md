# CORE1-E19 — Temporary Decision Continuation Protocol v2

## Status

Preregistered correction before any eight-seed evidence execution. Protocol v1
remains immutable. Its disconnected-receptor preflight is invalid mechanical
staging, not a scientific E19 result.

## Corrected inconsistency

Protocol v1 simultaneously required:

```text
completion signal returns to junction
```

and described the completion receptor as having no outgoing connection. The
implemented v1 preflight behaved exactly like a disconnected receptor:

```text
first route completed
completion SPIKE was positively delivered
OPEN remained OPEN
receptor had no path to the junction
no second route could participate
```

That cannot test the frozen hypothesis. A positive signal that cannot reach the
junction is not a completion return.

## Sole correction

The completion receptor is the local decision-junction return site. The
interaction is installed once at one physical context. When and only when the
receptor fires while the payload-free marker is OPEN, it admits one ordinary
junction wave to that context's already-existing candidate-source and
context-trace CELLs. This is the same physical input surface used by ordinary
junction activity; it is not an evaluator call to an action.

```text
route completes
        -> completion receptor fires
        -> if OPEN, existing junction CELLs receive one ordinary SPIKE wave
        -> existing local variation/decay/refractory physics decides what is live
```

The receptor still has:

- no direct motor/output connection;
- no Modulatory or consequence connection;
- no PQLC update rule;
- no action identity, preferred action, route, attempt, or timer state;
- no ability to initiate while CLOSED, because a delivered completion emits no
  junction wave unless the payload-free marker is OPEN.

The fixed context location is junction morphology, not an alternative
container in the OPEN marker. It names no selected route and adds no route
lifetime protection. Routes may exist after return only because ordinary
physical junction activity and variation recreate them.

## Unchanged contract

Every v1 opaque-screen target, mandatory control, rejection rule,
representation audit, one-shot evidence boundary, stop rule, and success claim
remains binding.

In particular:

- the marker remains exactly `CLOSED | OPEN`;
- one failed route permits exactly one new junction activation only after one
  delivered completion SPIKE;
- missing completion remains unable to produce another try;
- completion and consequence remain separate;
- only admitted consequence closes OPEN;
- no route or alternative receives lifetime protection;
- the eight-seed target remains `8/8`.

No other implementation or evaluator change is authorized by this correction.
