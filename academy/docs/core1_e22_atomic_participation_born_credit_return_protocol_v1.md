# CORE1-E22 — Atomic Participation-Born Credit Return Protocol v1

## Status

Preregistered before any E22 implementation or runtime observation. E22 tests
the timing boundary isolated by frozen E21 result `c36b14a`. It is a single
candidate, not a tournament, and grants no accepted physics or ARC authority by
itself.

## Question

When a generated contact actually transmits into its downstream route, is it
sufficient for that same physical participation event to create the temporary
topology by which later consequence reaches the contact and unchanged PQLC?

```text
contact -> downstream target traverses
  == same event ==
temporary returning -> contact Modulatory edge appears

forward admission later quiesces
completion later returns
consequence later fires returning CELL
temporary edge delivers Modulatory incidence to contact
existing local return/PQLC updates participating route
temporary edge disappears
```

## Sole candidate

The fixed local consequence-returning CELL is registered once as junction
morphology. During an actual action admission only, ordinary Drive traversal
examines its own physical source and target.

If and only if the traversing source CELL is a generated local subdivision
contact—physically witnessed by a live incoming Drive stem from a distinct CELL
at the same position—the traversal atomically creates one ordinary temporary
Modulatory edge from the registered returning CELL to that source contact.

Atomic means the return edge is live before the forward traversal event is
allowed to finish and before any later decay, completion, boundary return, or
quiescent inspection. The implementation may not reconstruct the contact from
diagnostics after propagation.

The edge contains no action, motor, route, path, context, episode, attempt,
reward, result, timer, deadline, or TTL payload. Its physical endpoints are its
complete state. If a live return edge already targets that contact, repeated
traversal does not need a duplicate edge.

The edge itself makes the target contact and its participating incident Drive
arrows part of live temporary return topology. Only those local structures are
protected from deallocation. Activation and participation relax normally. No
unrelated route or alternative is retained.

Completion cannot create, traverse, remove, or credit the edge. A later
ordinary consequence physically fires the returning CELL, traverses every live
temporary edge, and delivers ordinary Modulatory incidence to its target
contact. Existing PQLC alone may update material. After admitted consequence
finishes, temporary edges are removed and OPEN closes.

If consequence never arrives, the edge remains at natural quiescence. It does
not expire by time, silence, completion count, or another OPEN wake.

## Prohibited passive state

E20 USED-PENDING capture and protection are disabled throughout E22. Their
count must remain zero after route admission, after completion, and after
consequence. E22 may use no post-admission route/contact inspection to create
or preserve the edge.

The temporary physical connection itself is the only pending causal fact.

## P2-first gate

Before P1 or any matrix row, run useful-first seed 0 under Reference, exact
Reference replay, and Production. In both fixed opportunities require:

- route 1 physically participates;
- at least one return edge exists before that action admission reports natural
  quiescence;
- passive pending count is zero;
- completion is positively delivered before consequence;
- the same return-edge count remains after completion;
- ordinary consequence is admitted;
- Modulatory deliveries are nonzero;
- unchanged PQLC updates are nonzero;
- return-edge count becomes zero after consequence;
- OPEN changes to CLOSED only after consequence;
- route 1 is autonomous after the second consequence;
- bounded work, natural quiescence, exact replay, and mechanics equality hold.

Any failure stops E22. No P1, evidence marker, matrix, or repair is authorized
after a valid P2 failure.

## P1 composition gate

Only after P2 passes, run hard seed 7 under Reference, exact replay, and
Production. Require:

- the useful route 4 participates within four completions in both
  opportunities;
- every retry follows one delivered completion and one variation cycle;
- every participating generated contact creates its return edge atomically;
- passive pending remains zero;
- useful consequence produces nonzero Modulatory deliveries and PQLC updates;
- return edges clear and OPEN closes on consequence;
- route 4 becomes autonomous after two consequences;
- bounded work, natural quiescence, replay, and mechanics equality hold.

Multiple attempted contacts may leave multiple physical return edges. E22 has
no episode/action identity for choosing among them. P1 and the matrix must
expose rather than repair any resulting credit ambiguity.

## Eight-seed gate

Only after both preflights pass, emit the frozen one-shot evidence marker and
run all eight seeds once. Every seed must satisfy the complete P1 predicates,
including useful-route participation within four completions in both
opportunities, two nonzero consequence/PQLC events, final autonomous useful
action, zero passive pending, consequence cleanup, bounded work, quiescence,
exact replay, and mechanics equality.

Primary success is `8/8`; partial coverage earns no primitive.

## Mandatory controls

- CLOSED silence: no action and no return edge.
- OPEN action with completion withheld: one attempt, edge remains, no retry and
  no learning.
- CLOSED completion: delivered, zero variation cycles, zero edge traversal,
  zero learning.
- OPEN completion: preserves edge count and produces zero PQLC updates.
- Consequence without participating generated contact: zero E22 Modulatory
  delivery and zero E22 learning.
- Post-success completion: delivered but ineligible, with no edge and zero
  variation cycles.
- Non-contact Drive traversal: cannot create a return edge.

## Representation audit and rejection screen

Reject E22 if:

- return topology is created after propagation or quiescence;
- diagnostics/evaluator code supplies a contact, action, route, or path;
- a passive bit preserves the contact before edge creation;
- a nonparticipating or non-contact CELL receives an edge;
- completion, timeout, silence, or usefulness creates an edge;
- the edge directly changes learned material instead of delivering ordinary
  Modulatory incidence to existing PQLC;
- global route material is protected;
- successful consequence leaves an edge or OPEN live;
- exact replay, mechanics equality, bounded work, or quiescence fails.

## Frozen measurements

Per attempt record action, edge count at action return/completion/consequence,
passive pending count, completion delivery/cycles/work, consequence admission,
Modulatory deliveries, PQLC updates, OPEN transitions, total work, and natural
quiescence. Per seed record both attempt sequences, final autonomous action,
controls, replay, and mechanics equality.

Hash protocol, evaluator, preflight evidence, and any definitive matrix.

## Allowed implementation surface

2. an action-admission-scoped atomic-return capture flag;
3. same-traversal subdivision detection and temporary Modulatory edge genesis;
4. existing E21 topology-derived local retention, diagnostics, and
   consequence-triggered cleanup.

No accepted default, durable checkpoint schema, PQLC law, ARC policy, or prior
frozen evaluator may change.
