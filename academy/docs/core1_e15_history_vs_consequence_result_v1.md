# CORE1-E15 — history preference versus consequence-only result v1

## Outcome

History preference is an accelerator in this world, not a necessary organism
primitive.

Across eight balanced opaque action permutations:

| Arm | Before real consequence | After one consequence | After two consequences |
|---|---:|---:|---:|
| H — remembered useful evidence | 8/8 | 8/8 | 8/8 |
| C — consequence only | 0/8 | 0/8 | 8/8 |
| Seeded random control | 2/8 | 2/8 | 2/8 |

The actual exploratory action set and order were identical for H and C. Each
action began from an exact clone of the same unresolved physical snapshot.
Only the branch that produced distinguishing evidence continued through the
same two ordinary consequences.

## Arm H

The explicit arm-local memory retained the opaque action label whose effect
produced distinguishing evidence. That preference selected the already
established transient physical history on a later unresolved presentation.

It repeated the useful perturbation in every seed before any real consequence
was admitted. H therefore provides a real speed advantage.

This preference remains outside the accepted organism. E15 does not promote
it to physical law.

## Arm C

C stored no action label and received no informative-action signal. Before
consequence and after the first ordinary consequence, it emitted no action in
all eight seeds.

After the second consequence, it autonomously emitted the useful action in all
eight seeds without babbling or transient-history selection. The physical
route matured continuously:

```text
useful outgoing coupling
4,294,967,296
-> 16,840,355,296
-> 33,003,568,546

useful stem coupling
4,294,967,296
-> 27,817,569,796
-> 58,123,594,636
```

Each consequence delivered six ordinary Modulatory events. The first produced
15 local material updates and the second produced 25. The corresponding link
resistances also rose continuously. No target coupling, exploration score,
history label, or special information signal entered C.

## Random control

The preregistered deterministic random schedule selected the useful opaque
action exactly `2/8` times at every stage. It did not improve with experience.
This separates both learned policies from mere repeated exploration.

## Claim

The E15 outcome is the second interpretation branch anticipated by the frozen
protocol:

> Explicit memory that an action produced useful evidence can accelerate
> active experimentation, but ordinary downstream consequence and retained
> PQLC are sufficient to learn the same perturbation policy without that
> epistemic primitive.

This is development evidence, not an authority advance. The H mechanism is
not adopted.
