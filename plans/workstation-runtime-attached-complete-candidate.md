# Runtime-attached complete workstation candidate

```text
world sample -> accepted workstation receptors -> unchanged learner/output/body
           \-> one runtime attachment path -> short physical trace + local calibration
                                                 |
key -> glyph -> retained return -> cue -> look -> reach -> touch -> press -> release -> quiet

one owned body transition -> one transaction -> locally reused topology
one Academy campaign      -> visible stages -> bounded boundary replay
```

## Outcome

The existing complete workstation constructor can opt into one runtime attachment
surface spanning binocular retinal values, palm/fingertip contact values, and all
eye, palm, and finger proprioceptive values. The same owned world observation
fans out to the accepted receptor and attached tissue with one physical cause;
action-caused samples retain the exact output origin. Body-curried calibration
adds persistent residual tissue only for the body's local interior-vs-limit
relation. The learner law, device world, full ANSI keyboard, collision, monitor
rendering, and evaluator boundary remain unchanged.

One discovery campaign develops ordinary key-to-monitor consequences and then
climbs cue render, retinal change, learner/path reuse, gaze/search, reach,
contact, press, visible result, release, and natural quiet from one complete
candidate. It preserves a compact arrow-by-arrow projection and stops the
capability claim at the first missing physical transition.

## Model

The domain objects are an owned `WorldSample`, the accepted workstation receptor
frame, a `RuntimeAttachedSurface`, the private `Harness`, outward body effects,
and Academy-only ladder evidence.

The runtime surface owns anonymous `PhysicalTraceComponent` attachments. One
pure observation projection maps binocular, contact, and proprioceptive values
to bounded ordinal samples. A second pure projection curries each axis's local
body relation into a `Residual`: interior is identity and a physical limit is
nonzero need. Attached trace state, not an adapter-side previous-value cache,
separates rises, falls, persistence, and quiet. A caused sample uses the exact
participating output origin and `Transition`; an ordinary observation uses its
attached physical origin and `Sample`.

One owned world observation is a product of simultaneous sensor facts. The
projection therefore preserves its moment: independent focused-field changes,
raw attached samples, and calibration samples share the observation tick and
input phase. Only links inside a physical component may introduce later causal
phases. A feature index identifies a product factor; it is not time.

Construction, observation fanout, physical send, body integration, world
advance, checkpointing, and evidence serialization remain explicit effects.
Attachment failure, invalid restored ports, invalid observation cardinality,
replay mismatch, semantic leakage, and a missing ladder arrow fail closed.

At each physical scale, a state and an input compose to a new state plus owned
observation. The workstation exposes this transition without committing it so
Academy can compose body and world atomically with one body clone. The owned
candidate then consumes its core send directly; it does not open a second
transaction around a state already isolated by the outer transition.

Connected outcome components are a derived view of live physical topology.
Competition asks only for components containing candidate outcome sources, so
the implementation traverses those requested components instead of
materializing disconnected sensor tissue. The projection still charges the
complete logical `Work`; physical history and evidence therefore remain exact
while the mechanical representation stays outside checkpoints.

Fingerprints preserve the product boundary. The core checkpoint is encoded
once; workstation identity combines that core digest with workstation-owned
state; session identity combines workstation and world digests with sequence.
Sensing reads only the already-owned public workstation state and does not
construct fingerprints that the step does not consume.

Academy execution reports its stage and cumulative body steps outside physical
time. Development retains one complete exact replay because it constructs the
shared organism. Each counterfactual probe runs once and replays its exact first
boundary transition, including the resulting checkpoint. Once the shared
checkpoint exists, development replay and the four probes are independent
product branches: they execute concurrently with the two paired invariant
reads, then join in the same deterministic evidence order. Each probe's primary
and replay branches do the same. This tests every restore/presentation boundary
without serializing independent worlds. The evidence records the advertised
maximum and actual primary/replay counts.

## Invariants

- No key identity, glyph meaning, target coordinate, desired gaze, desired
  finger, route, correctness bit, score, or evaluator decision enters the
  harness.
- Academy continues to own presentation and scoring; the organism sees only
  pixels, proprioception, touch/pressure, ordinary opportunity, and device
  consequence.
- Runtime attachment is inert at construction and changes no pose, learner
  fingerprint, output, outcome, or physical clock before an observation.
- Accepted workstation receptor inputs and attached inputs share the same cause;
  attachment does not read the world independently.
- Independent facts from one sensor frame remain simultaneous. Neither feature
  order nor modality order may become an invented sequence of physical moments.
- Only an actual action-caused sensor observation carries that action's physical
  origin. Unchanged or passive observations do not fabricate return.
- Calibration uses only a body-local relation. Zero is identity, nonzero need
  persists as `Sample`, falls carry outcome, and rises stay distinct.
- Vision and contact receive no invented normal, target, or correctness
  relation. Axis calibration does not encode a direction or motor map.
- Full ANSI geometry, five digits, collision/contact, focused field, binocular
  movement/fixation factors, output-specific return, first-choice lifetime,
  replay, and natural quiescence remain present.
- Existing constructors and versioned checkpoints restore identically with no
  attachment. Attached checkpoints restore the exact next step.
- Candidate-local connected-topology projection produces the same component
  keys and complete logical work after link connection and retirement.
- Direct owned send and the existing transactional send are extensionally
  equal. Exactly one scale owns rollback for an Academy workstation step.
- Fingerprint composition is causally inert and changes whenever any body,
  world, presentation, device, or sequence checkpoint component changes.
- Progress and replay schedules remain evaluator-only and never enter physical
  time, sensor input, choice, output, outcome, or learner state.
- Raw generated recordings remain ignored; tracked evidence is a compact causal
  projection with bounded size.

## Controls and evidence

- Held-out cases: paired proper printable keys from one checkpoint, blank cue,
  unlearned glyph, complete development replay, and exact first-transition plus
  checkpoint replay at every probe boundary.
- Negative controls: construction before any observation, identical resample,
  keyboard unavailable, cue absent, centered gaze without a closed hand
  relation, neighboring/stuck key, and no action-origin return from a passive
  change.
- Falsifiers: any hidden semantic field; attachment-created action or learner
  change; lost action origin; fabricated transition from passive input; replay
  mismatch; non-quiescent step; raw trace growth; or inability to locate one
  earliest missing arrow.
- Evidence: validated campaign and arm manifests, one compact JSON projection
  containing every ladder arrow and control result, hashes of any local raw
  diagnostics, exact commands and durations, candidate receipt, independent
  verification receipt, and validated convergence.

## Risks and rollback

The main risks are duplicate-cause admission, attached topology exceeding the
focused harness capacity, checkpoint migration drift, broad calibration drive,
and large evidence. Tests compare cause/origin identity, construction reads,
old checkpoint fixtures, exact replay, active work, and artifact size. The
feature is research-only and opt-in; rollback removes the opt-in surface and
campaign while leaving existing constructors and accepted learner physics
unchanged. A scientific failure retains its compact projection and rolls back
no evidence.

## Retained preflight

The first attempted broad run was stopped before it could become evidence. A
process sample found all sampled CPU time below repeated global causal-topology
component reconstruction. The upstream counterexample was already visible at
the harness boundary: a single runtime observation assigned a different phase
to each of roughly 180 attached inputs, and a focused image could assign a
different phase to thousands of changed factors. This did not preserve the
product structure of a sensor frame and made the run cost-inadmissible. The
candidate solve is the frame-moment law above, not removal of sensor coverage.
The next full run is valid only after a focused test proves simultaneous input
incidence and the warm representative gate remains below ten seconds.

The next preflight exposed two further cost multipliers. First, restore checked
each local port by repeatedly materializing the global organism; the local
validity query reduced the warm full-surface gate from 6.21 seconds to 1.69
seconds. Second, the user-stopped 64/64 run consumed 510.23 wall seconds and
467.52 CPU seconds while remaining bounded near 120 MiB. Static accounting
showed that the two advertised budgets expanded to at most 416 body steps
because development, two learned probes, and two controls were each replayed in
full. Code inspection also found repeated full checkpoint fingerprints, nested
body transactions, and unchanged connected-topology reconstruction. No
scientific result was produced and no evidence file was written. The successor
must make its execution count visible, reduce the maximum to 276 steps under
the boundary-replay law, and pass topology-projection and owned/transactional
identity gates before another comprehensive run.

The final cost trace showed the same global-search mistake at smaller scales:
incidence grouping linearly searched a growing batch, physical origins and
vacant arena slots linearly searched the whole organism, connected competition
materialized every disconnected sensor component, and pure-Rust SHA-256
dominated the remaining evidence path. Dense incidence slots, derived
physical-ID and ordered-vacancy indexes, requested-component traversal with
unchanged logical work, and the compatible SHA-256 assembly backend removed
those representation costs. Finally, frozen-state replay and the four probe
worlds were recognized as independent product branches and executed
concurrently before deterministic rejoining. After the paired invariant reads
joined the same product, ten consecutive warm runs completed between 0.25 and
0.32 seconds with all twelve body transitions, controls, replay comparisons,
and sensor modalities intact.
