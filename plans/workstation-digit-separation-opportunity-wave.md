# Test sparse generic opportunity across physical components

```text
shared generic wave -> choose one least-used outcome component
                                      |
                                      v
                         ordinary local sign choice -> output

distinct physical waves -> each chooses locally -> outputs compose
```

## Outcome

Implement the smallest surviving preregistered discovery subject for
`workstation-digit-separation-opportunity-wave-v1`: represent one generic
workstation opportunity as one physical phase/origin and reuse the accepted
causal-origin choice plus topology-local product. The larger proposed outer
wave selector stopped after this smaller arm satisfied the frozen morphology
predicate.

This produces development evidence for the frozen campaign. It does not change
the default `WorkstationHarness`, accepted protocol, checkpoint bytes, authority,
or any digit/contact/device capability claim.

## Model

- Keep `RecursiveLearnerCausalTopologyProductComposition` unchanged. Its
  existing causal-origin factorization already treats one origin as bounded
  alternatives, while its accepted topology product composes distinct origins.
- Change only the research workstation incidence: all generic motor
  opportunities in one external step carry one phase and one physical origin.
  This states the real causal fact once instead of inventing one cause per
  motor.
- Reuse the existing `CandidateSelection` diagnostic to prove the bounded
  shared-origin choice. No new core event, state, selector, or protocol is
  added.
- Add research-feature-only constructors to `truelearner-workstation` and
  `academy-workstation`. The default constructor keeps distinct motor phases
  and origins. The shared mode assigns all generic motor opportunities in one
  external step one phase and one origin; it does not choose an axis or digit.
  Default checkpoint encoding remains byte-identical. Research restore receives
  the frozen incidence mode explicitly beside the opaque checkpoint.
- Add `research/experiments/workstation-digit-separation`, which runs all four
  frozen arms, writes neutral result JSON, checks exact replay by restoring the
  same checkpoint with the frozen research mode, and never enters a production
  workspace dependency.

## Invariants

- Default `Protocol` values, `WorkstationHarness::new`, physical history,
  checkpoint bytes, fingerprints, and tests remain exact.
- One connected component preserves the exact accepted arrow. Two independently
  originated components both survive regardless of registration order.
- One shared origin admits candidates from at most one disconnected component
  per wave while retaining ordinary alternatives inside that component.
- Choice uses only the already-carried physical origin and accepted learner
  structure. It cannot inspect axis, digit, pose, target, contact, device
  state, capability, or evaluator outcome.
- Shared incidence changes only generic motor opportunity phase/origin; sensory
  samples and actual transition returns retain their original physical facts.
- Trace observation does not affect ranking, state, physical time, or replay.
- Every arm stops on its first frozen falsifier and preserves negative output.
- Research results are development evidence only; factory receipts are software
  evidence only.
- The representative warm regression remains strictly under 10 seconds.

## Controls and evidence

- Held-out cases: two distinct origins in one phase, one shared origin across
  the full morphology, and restored shared-incidence execution.
- Negative controls: exact default checkpoint bytes and observations; shared
  incidence alone; accepted one/two/five serial histories; unrelated origin;
  no direct opportunity; semantic-wire audit; corrupted result rejection.
- Laws: one-component identity; order-invariant component choice; distinct-wave
  composition; encode/restore identity under an explicitly frozen research
  mode; tracing is inert.
- Falsifiers: any default drift, shared-wave multi-component firing, independent
  suppression, permanent lowest-key monopoly after participation differs,
  semantic selection, replay divergence, non-quiescence, exhaustion, or cost
  bound failure.
- Evidence: validated forecast/protocol/campaign/plan; four immutable arm result
  JSON files; exact trace and subject digests; E2B batch outputs; convergence;
  candidate and independent software verification receipts.

## Risks and rollback

- A new outer selector would duplicate existing causal-origin choice and risk
  global suppression. The frozen downward arm prevents adding it after shared
  incidence alone succeeds.
- Research configuration can leak into default persistence. Keep incidence mode
  out of the default checkpoint payload and require it explicitly only on
  feature-gated research restore.
- Roll back the opt-in protocol, feature-gated constructors, experiment, and
  campaign artifacts. The clean parent and generated videos remain unchanged.
