# Retain first, then localize the tick-forty-seven arrow

## Outcome

Run the unchanged construction-composition hand once, retain the complete
`ReflectedHandProtocolEvidence` regardless of the analysis verdict, and use a
pure fold to identify which tick-forty-four learner-three projection physically
completes target ten at tick forty-seven. No organism or adapter behavior
changes.

## Authority

- Path: `research/campaigns/hand-construction-projection-admission-retention-v1/convergence.toml`
- Revision: `sha256:d2a48374196d47bbe14baf79bafd7be3062748c8d87de85258be02e0a4c35a19`

## Model

The complete hand evidence is the immutable diagnostic snapshot. Analysis is a
total pure function over that snapshot; its result is stored beside, never in
place of, the input evidence. The fold selects the tick-forty-seven choice by
tick and phase, requires learner three, target ten, `Unique`, and
`CompletedCycle`, then intersects learner-three consequences created at tick
forty-four with tick-forty-seven drive events that complete target ten and
causal-lineage events carrying the same link generation.

Category-theoretically, construction projections are candidate arrows and the
tick-forty-seven path is their downstream composition. A link survives the
diagnostic only when the same physical identity and generation make that
triangle commute. The emitted Rust remains a small typed fold.

## Invariants

- Prior frozen artifacts and source remain unchanged.
- Core, learner memory, choice, recency, adapter, and hand physics remain
  unchanged.
- The full snapshot is present for survived, falsified, and insufficient
  verdicts.
- Matching uses tick, phase, learner, target, link, generation, consequence
  tick, and physical path completion only.
- No position, direction, hand, expected action, or evaluator answer enters
  localization.
- The candidate hand runs once after plan, campaign, candidate, and independent
  verification succeed.

## Scope

- Add one evidence-only Rust experiment and one frozen diagnostic campaign.
- Reuse the public full hand evidence and existing witness events.
- Add synthetic tests for exact physical intersection and insufficient
  composition without running the hand.
- Exclude all learner-physics and adapter changes.

## Controls and evidence

Held-out cases are a same-link wrong-generation lineage event and a projected
link that drives but does not complete the target. Negative controls are the
prior tick-forty-seven choice fact, the three tick-forty-four projected links,
exact replay, natural quiescence, zero propagation exhaustion, and the
unchanged external hand summary. The campaign survives only if the full
snapshot is retained and at least one of links 33, 34, and 41 composes with the
same generation into target ten at tick 47.

## Risks and rollback

The main risk is again reducing evidence on a failure branch. The raw snapshot
is therefore an unconditional top-level artifact field. Rollback removes only
the new experiment and campaign.
