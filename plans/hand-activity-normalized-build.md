# Build the reflected hand through its next physical wall

## Outcome

Replace repeated timing-wheel minimum searches with one linear extraction of the
earliest causal wave. Then add one opt-in learner protocol that lets a uniquely
current, return-bearing path accept the existing local opportunity while its real
movement outcome is still returning. Run the unchanged reflected joint through
both limits and perturbation recovery, or preserve its first failed transition.
This is development evidence only; accepted-default authority is unchanged.

## Model

The scheduler maps a finite multiset of firings to the earliest causal-wave batch
and a residual schedule. Extracting all members of the selected prefix at once
must preserve the old serial order and the residual schedule exactly. Its measured
ordering comparisons must grow linearly with scheduled items.

The hand wall is an ordering gap between a real movement transition and its later
outcome. A blocked motor path may already carry the current owner-local transition
and a live unanswered return. The new protocol composes the established bounded
local opportunity with that exact return-bearing path, making it executable. That
uniquely promoted path continues first. At the next observed cancellation, several
paths carry the same real transition; the path with the unique latest actual outcome
continues instead of an older unanswered path. The real transition bounds this
comparison. The one-time held construction outcome remains the more specific
witness and keeps priority; an ordinary completed outcome yields to a sample-only
no-change release when more than one anonymous physical path origin is currently
present, as at a contact boundary. No global recency window or direction memory is
extended. When every candidate lacks a current real transition, the unchanged
sample cannot continue the old path; an already executable fresh alternative may
instead replace its unanswered return. Ambiguous latest outcomes, ownership
mismatches, and missing alternatives remain unchanged.

A second form of the same local arrow occurs before a donor return exists: a
balanced blocked path already carries the current owner-local physical transition.
The transition itself may supply one existing opportunity unit to that exact path,
allowing it to enter ordinary competition. It does not select the path and cannot
act through a sample or a path not reached by the transition.

## Invariants

- Timing-wheel extraction preserves causal order, outputs, replay, quiescence,
  body state, and Production/reference equality; only mechanical cost changes.
- Ordering comparisons and batch scans are measured explicitly and remain linear
  in the extracted wave size.
- The new learner behavior is opt-in and composes every established prerequisite
  of `RecursiveLearnerBoundedConstructionContinuation`.
- Opportunity is admitted only for a locally blocked path that carries a current
  owner transition, either directly from that transition or through the established
  local return-bearing transfer.
- Current-transition choice first admits one exact promoted return-bearing path;
  otherwise it requires one uniquely latest actual owner-local outcome.
- No position, direction, hand, joint, contact, target, score, step, or evaluator
  identity enters the organism.
- A physical sample cannot trigger continuation. It can release an unanswered path
  only through the already bounded local fresh-alternative rule when multiple
  anonymous physical path origins are co-present.
- An ownership mismatch, tied latest outcome, missing alternative, or non-local
  candidate cannot trigger the new choice.
- Exact replay, natural quiescence, zero propagation exhaustion, bounded work,
  frozen predecessor hashes, and all inherited controls remain required.
- No accepted default, architecture oracle, or frozen predecessor is changed.

## Controls and evidence

Held-out scheduler cases mix equal-tick phases, causal waves, and later ticks and
vary wave size through at least a sixteen-fold range. Negative controls cover sample,
no-return, non-current-return, ambiguous-transition, ownership mismatch, duplicate
reuse, exact parent behavior, step-nine output signs, both limits, both escapes,
reflection, perturbation, replay, quiescence, and work. Killing falsifiers are
superlinear measured comparisons, changed causal ordering, continuation without
the exact current return, remaining step-nine cancellation, failure to reach and
leave both limits, failed recovery, exhaustion, or inherited-control drift.

Because the worktree has no clean named pre-benchmark commit, this turn may produce
validated development evidence but must not claim frozen benchmark authority.

## Risks and rollback

Stable extraction could accidentally reorder equal-time firings; mixed-prefix and
full regression equality tests detect that. Return-bearing promotion could become
a persistent direction lock; samples, duplicate use, opposite escape, perturbation,
and quiescence controls detect that. Rollback removes the new protocol and restores
the old repeated scheduler extraction without touching predecessor artifacts.
